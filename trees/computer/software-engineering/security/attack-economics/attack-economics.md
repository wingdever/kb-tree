# 攻击的成本面

评估入侵损失时，"有没有数据被拿走"只是一个维度。对以扫描、代理、挖矿为目的的攻击者而言，数据价值低并不降低这台机器的价值。

## 带宽账单

按流量计费的实例，出站流量会直接变成费用。持续的小包外发在账单上不一定显眼，但乘以月数就会变成可观的数字。即使不按流量计费，出站带宽被打满也会挤占正常服务。

## IP 信誉

对外攻击会让地址进入各类黑名单：邮件被拒、接口被限流、合作方主动封禁。服务恢复是小时级，信誉恢复是月级——这是被入侵后最容易被低估的长期成本。

## 滥用投诉

云厂商会对异常出站与对外攻击发出工单，处置手段包括限速、停机、封禁实例。这类处置通常比攻击本身更快打断业务，也会影响同一账号下的其他实例。

## 被征用的算力

攻击者要的不是数据，是出口和执行能力：一批可用的源地址、一段稳定的带宽、一个能跑任务的 CPU 份额。一台没有数据的机器，照样是僵尸网络里合格的一员。

## 可观测的成本指标

- 出站字节与入站字节的比例，偏离业务形态即为异常。
- 单位时间新建连接数，与服务峰值不符时说明在做非业务连接。
- 出站包数与包长的组合，用于区分"搬运"与"敲门"。
- 远端端口分布，长期集中在同一个端口说明行为单一。

这些指标同时也是检测信号：成本上升与入侵迹象通常出现在同一组数字上。
