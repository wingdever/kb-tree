# 特殊文档切块

固定大小切块会切坏结构化内容：把表格行从表头撕开、把条件句拆到两块、把图注与图片分离。**按格式的知识单元切，而不是按字符数切**——这是本页的全部。

## 通用原则

- **结构优先，大小其次**：已知格式就按它的单位切（标题、段落、列表、表格、函数）；未知文本才回退到递归切分（段落→行→句，约 200–400 token）。
- **给每块附加章节路径**（如"报销政策 > 差旅 > 酒店标准"）——最便宜的改进，无需模型调用。
- **绝不切开标点**：表格行不与表头分离，图注不与图片分离，代码块不拦腰截断。
- **解析先于切块**：PDF 是布局而非 token 流，先做版面分析再切。

## 按内容类型选边界

| 内容 | 合适边界 | 必须保留的上下文 |
|---|---|---|
| 文章/报告 | 标题 + 段落 | 标题、章节、日期 |
| 文档/API | 概念 / 端点 + 参数 + 示例 + 错误 | 产品、版本、层级 |
| FAQ | 问题 + 答案 | 类别、语言 |
| 法律 | 条款 / 子条款 | 司法辖区、生效日期 |
| 代码 | 函数 / 类 / 模块 | 文件路径、语言、符号名、父上下文 |
| PDF 报告 | 章节感知块 | 页码、标题、日期 |
| 表格 | 表头 + 相关行（整表或行组） | 表标题、列名 |
| 转录 | 说话人 / 主题窗口 | 会议 ID、说话人、时间戳 |

## 表格

朴素切分会把数值与表头分离，让块失去意义。大表要让每一行（或行组）都带上表头与表身份；或转成文字描述。**绝不从表中间切开**。

NVIDIA 2025 厂商基准中，页级切块（把表格与图表作为完整单元保留）在被测配置下端到端答案准确率最高——这是对该语料的证据，不是普适结论。

## 代码

按语义单元切：模块、类、函数、方法、接口、配置块。每块保留文件路径、语言、符号名、符号类型、父类、仓库版本。超大函数可再切，但每个子块要保留签名与父上下文才可知其用途。树的 AST / tree-sitter 比字符切分可靠得多。

## PDF 与扫描件

PDF 是高风险输入：多栏文档在朴素抽取下会左右栏交错、表格被摊成丢列头的行流、页眉页脚混入正文、脚注与正文交织。

- **版面分析优先**：先识别物理区域，按逻辑阅读顺序抽取，保留表格、列表、代码块，去重复页眉页脚。
- **2026 版面感知解析器是基线**：Marker（datalab，转 Markdown + 表格/图检测，GPU 加速）、Docling（IBM，结构化表示含表格/列表/图/代码块）、Unstructured（格式覆盖广，带元素类别标签）、Microsoft Document Intelligence（云，表单表格高精度）、LlamaParse、Google Layout Parser。输出是结构化文档模型，不是纯文本——切块在结构上做，不在摊平的文本上做。
- **扫描件**：先做版面分析再 OCR。OCR 把表格摊平会丢字段关系；带重试的版本化摄入管线很重要（解析器升级要能重处理，OCR 临时失败要能按页范围重试）。
- **页 ≠ 理想块**：章节感知块通常比"一页一块"更有用，但要保留页码元数据供溯源。
- 每块带标题、页码、章节、版本、发布日期、图表引用。

## 幻灯片（PPT）

幻灯片是更奇怪的单元：画布上只有五个词、一张图、三个箭头，而真正的语义在 300 字的演讲者备注里。只索引可见文本 → 近乎空；只索引备注 → 丢失视觉证据。

**单元 = 幻灯片本身**：标题 + 画布文字 + 演讲者备注 + 渲染图像，作为一个多通道块。多模态嵌入（Voyage multimodal-3、Cohere Embed v4）可把渲染图本身纳入块向量。密集页面/幻灯片也可考虑整页图像检索：ColPali 把页面截图编码为约 1024 个 patch 向量做延迟交互，在 ViDiRe 上 nDCG@5 81.3 vs 解析+描述流水线的 67.0（论文数字）。

## 转录稿

单轮话语往往太小（"对，那样可行"依赖上文）。用多轮窗口、主题段或说话人感知窗口，保留会议 ID、说话人、时间戳、主题。

## 图片与图表

两条路：

- **描述法**：视觉模型写描述，与图注/章节一起嵌入（Unstructured、Docling、Azure AI Search、Bedrock）。一张图一次模型调用；AWS 自评其对技术图"提取文字标签但遗漏视觉关系"，评级有限。
- **直接嵌入图像**：多模态模型把图（或图文）变成向量（Gemini Embedding 2、Voyage multimodal-3.5、Cohere Embed）。Azure 建议照片/截图用此路，图表用描述。
- **整页嵌入**：ColPali 适合幻灯片与密集页面。

关键是把图与引用它的文字**双向链接**——检索到任一方都能返回另一方，原图随块一起送回，让多模态模型能读真实图表。Docling 默认跳过页面面积 <5% 的装饰图。特殊地，"见图 3"这类跨文档引用需要额外做模式匹配来解析——主流平台均未提供。

## 数据质量护栏

页面级/结构级切块只在源数据可信时有效。Pryon 医疗 RAG 研究：限定在高质量策展内容时幻觉趋近于零，同样检索架构喂未 vet 数据时 52% 的问题产生编造答案。Gartner 调查：63% 组织缺乏 AI-ready 数据实践，预计 2026 年 60% 的 AI 项目因数据未就绪被放弃。切块再精，垃圾进仍垃圾出。
