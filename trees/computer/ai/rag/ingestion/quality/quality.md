# 抓取质量

抓取最容易陷入“页数增长”的错觉：URL 数、请求数、存储量都在涨，但真正可检索的正文没有变多。质量评估要把“抓了多少”换成“抓对了多少、更新得及不及时、文本干不干净”。

## 六个核心指标

| 指标 | 回答的问题 | 采集方式 |
|---|---|---|
| 覆盖率 | 目标实体/页面抓到了多少 | 与权威清单、站点地图或抽样比对 |
| 新鲜度 | 内容距上次变化/抓取多久 | `fetched_at`、`lastmod`、版本链 |
| 抓取成功率 | 请求成功且非软 404 的比例 | 状态码 + 内容判定 |
| 解析成功率 | 正文与关键字段是否抽出 | 解析器日志 + 人工抽样 |
| 正文比例 | 正文占原始文本的比例 | 正文长度 / 全文本长度 |
| 重复率 | URL 与内容重复占入库量 | 去重命中与抽样 |

再加两个成本指标：每千条有效记录的抓取成本、每万字的解析/渲染成本。没有成本分母，质量提升无法比较。

## 评估方法

- **黄金集**：人工标注一批页面，覆盖不同站点、版式与内容类型；每次改抓取/解析规则都回归。
- **分层抽样**：按站点、模板、内容类型分层，不要只抽头部站点；长尾往往才是失败集中区。
- **端到端评估**：不只看出库页数，还要看检索命中与答案引用；抓取质量最终由下游检索结果检验。
- **漂移监控**：正文比例、解析成功率、重复率突然变化，通常意味着站点改版或规则失效。

## 质量门禁

入库前设硬门槛：

- 抓取失败或软 404 → 不入库；
- 正文长度过短或正文比例过低 → 标记待复核；
- 与已有内容近重复 → 合并或跳过；
- 关键字段缺失（标题、来源、时间）→ 降级或补采。

门禁不是为了追求完美，而是防止噪声批量进入索引后难以清理。

## 常见误判

- **用抓取量代替质量**：页面数增长可能只是重复与模板页增长。
- **只看状态码**：200 也可能是软 404、登录页或错误页。
- **只看离线指标**：抓取覆盖率很高，但检索仍然答错；要回到端到端评估。
- **没有基线**：改规则后感觉变好，却说不清提升了哪一项。

## 一句话主线

用覆盖率、新鲜度、成功率、正文比例与重复率衡量抓取，再用黄金集、分层抽样与端到端检索评估校验；抓取质量的目标是“可检索的干净文本”，不是“更多的页面”。
