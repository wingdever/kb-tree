# 微调多维坐标

三界两轴回答“微调是什么”；这里回答“这一次微调是什么形态”。两者不冲突：前者是本体定位，后者是可检索、可组合的分类坐标。

## 先分清“正交”的含义

这里的正交，指每个轴可以独立取值、允许交叉组合，不是统计上互不相关。参数范围、数据规模、部署形态天然有相关性，但作为分类坐标仍然可以分开记录。PEFT 主要落在 P2，但 PEFT 不等于微调全部。成本、可逆性、遗忘风险不是轴，而是由多个轴算出来的派生指标。

## 八个轴与刻度

| 轴 | 刻度 | 说明 |
| --- | --- | --- |
| P 参数范围 | P0 不训练 / P1 软提示 / P2 adapter 或 LoRA / P3 部分层 / P4 全参数微调 | 改多少参数 |
| S 监督信号 | S0 继续预训练 / S1 SFT / S2 偏好对齐 / S3 奖励或 RL / S4 蒸馏 | 用什么信号训练 |
| N 数据规模 | N0 零或极少 / N1 小 / N2 中 / N3 大 | 有多少样本 |
| Δ 领域距离 | Δ0 同域 / Δ1 邻域 / Δ2 远域 | 数据离基座分布多远 |
| C 目标能力 | C1 格式与风格 / C2 知识与事实 / C3 推理 / C4 工具与行动 / C5 安全与拒答 | 多标签，不是等级 |
| E 部署形态 | E1 合并单模型 / E2 单 adapter / E3 多 adapter 路由 | 权重怎么组织与路由 |
| Q 数值精度 | Q1 bf16 或 fp16 / Q2 int8 / Q3 4bit | 服务精度 |
| G 治理等级 | G1 实验 / G2 内部生产 / G3 公开产品 / G4 高风险或强合规 | 评估、灰度与回滚要求 |

## 刻度怎么读

- P、E、Q、G 是离散等级，适合筛选与比较。
- S 是训练目标链，不是“越往后越高级”；S1 与 S2 解决不同问题。
- N、Δ 是区间刻度，不是精确阈值；阈值随模型、任务与数据质量变化。
- C 是多标签轴：一次微调可以同时指向格式与工具调用，不要强行排等级。
- 刻度不是评分表。P4 不比 P2 更好，只表示代价与容量不同。

## 组合示例

- 格式微调：`P2 / S1 / N1 / Δ0 / C1 / E3 / Q1 / G2`，LoRA SFT，多租户 adapter 路由。
- 领域知识：`P4 / S1 / N3 / Δ2 / C2 / E1 / Q1 / G3`，全参 SFT；但仍要先判断 RAG 是否更合适。
- 安全偏好：`P2 / S2 / N1 / Δ0 / C5 / E2 / Q1 / G3`，LoRA 偏好对齐，单独 adapter 灰度。
- 端侧格式：`P2 / S1 / N1 / Δ0 / C1 / E2 / Q3 / G2`，小数据 LoRA，4bit 端侧部署。

## 哪些不是轴

- **成本**：由 P、N、S、E、Q、G 共同决定，不是独立维度。
- **可逆性**：主要由 P 与 E 决定；全参合并难回滚，adapter 易切换。
- **遗忘风险**：由 P、N、Δ 与 S 的强度共同决定。
- **评估强度**：由 C 与 G 决定；高风险能力不能只用任务准确率。

## 一句话主线

微调可以用八个正交刻度定位；轴用来描述形态，成本、可逆性与风险用来做决策，不要把派生指标伪装成轴。
