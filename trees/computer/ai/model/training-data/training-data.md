# 训练数据来源

"训练数据从哪来"不是一个问题，而是四个：预训练要万亿级 token 的通用语料，SFT 要几千到几十万条高质量示范，偏好对齐要成对的排序标注，可验证奖励要能自动判分的题目。四类数据的获取渠道、成本与法律风险完全不同，混在一起谈就会得出"数据不够用"或"数据随便爬"这两种错误结论。

## 按阶段分四类

| 阶段 | 数据形态 | 量级直觉 | 主要来源 |
|---|---|---|---|
| 预训练 | 去重过滤后的网页文本、代码、论文、书籍、百科 | 万亿 token | 公开爬取语料、开放许可文本、自有积累 |
| 中训练 / 退火 | 高质量文档、数学与代码、合成数据上采样 | 百亿 token 级 | 精选公开集、自有高优数据 |
| 监督微调（SFT） | 指令 + 示范回答 | 几千到几十万条 | 开源指令集、人工标注、业务日志改写、合成 |
| 偏好对齐 / RLVR | 成对排序、可自动判分的题目 | 几万到几十万条 | 人工标注、模型评判、题库与规则校验 |

量级差了几个数量级，所以"数据不够"通常指 SFT 与偏好数据不够，而不是网页不够——公开网页到 2026 年仍然是 PB 级，真正的瓶颈是高质量、可授权、可判分的数据。

## 开放数据集平台

- **Hugging Face Datasets**：全球最大的聚合入口，2026 年 8 月披露数据集数量约 100 万个，模型侧超过 300 万个；优点是格式统一（Parquet + datasets 库），缺点是许可混杂，需逐个看卡片。
- **魔搭 ModelScope**：境内直连，数据集检索结果约 5 万个，中文与多模态数据占比高，下载不受跨境链路影响。
- **OpenDataLab**：面向国产大模型的开放数据平台，数据集 7700 个以上、总量 220TB 级，覆盖文本、图片、音视频与多模态，提供 CLI/SDK 批量下载。
- **Kaggle Datasets**：竞赛与表格数据强，适合小规模实验与基线复现，许可同样要逐条确认。
- **Common Crawl 及衍生语料**：原始网页存档免费开放，但要用得自己清洗；基于它派生的清洗版语料（如 C4、FineWeb、DCLM 一类）才是可训练的形态。
- **图像与多模态**：LAION 系、DataComp 系提供图文对，但经历过下架与重建，使用前必须核对当前版本与内容审核状态。

## 自采、标注与合成

公开数据覆盖不到的，只有三条路：

1. **自采**：爬取公开网页、抓取自有业务日志、录制传感器数据。爬取要遵守目标站点的 robots 与服务条款，避开登录后内容与个人信息。
2. **人工标注**：自有团队标注、众包平台、专业机构采购。SFT 阶段几百到几千条精标数据，往往比几万条脏数据更有效。
3. **合成数据**：用强模型生成指令、答案、推理链，再用规则或模型筛掉错误样本。常见做法是从少量种子指令扩写成千上万条，或用强模型的对话记录改写。

合成数据有两条硬约束：**上游模型的输出许可**（不少厂商禁止用其输出去训练竞品模型）、**错误放大**（教师模型的幻觉会被学生模型学走，必须有校验环节）。

## 许可与合规

- **许可证分级**：CC0、CC-BY、Apache-2.0、MIT 这类宽松许可可商用；CC-BY-NC 及"仅研究用途"的数据不能进商用模型；无许可证的公开数据默认保留所有权利。
- **爬取条款**：多数网站的服务条款禁止批量抓取，robots.txt 是底线而非全部；登录墙后的内容风险更高。
- **个人信息**：训练语料中的手机号、身份证号、住址、聊天记录属于个人信息，必须做 PII 识别与去除，否则从收集环节就不合法。
- **数据出境**：把境内采集的数据传到境外训练，涉及出境评估与申报，不能因为"只是训练"就跳过。
- **生成式服务合规**：面向境内提供生成式 AI 服务，监管要求训练数据来源合法、不侵害他人权益，并留存来源记录以备核查。
- **版权争议**：即使数据公开可下载，也不等于可以无条件用于训练；商用模型应优先选择明确许可或公有领域语料。

> 判断：合规成本不在"下载"这一步，而在"证明来源"这一步——能说清每条数据的许可、采集时间与清洗方式，比多囤几个 TB 更有价值。

## 清洗与配比

原始数据几乎不能直接训练，标准管线是：解析抽取 → 语言识别 → 去重（精确 + 近似）→ 启发式过滤（长度、符号比例、重复行）→ 分类器打分（质量、毒性、PII）→ 配比混合。

配比是隐形的能力开关：代码比例高会提升推理，百科与论文比例高会提升事实性，多语言比例决定小语种表现。配比没有普适最优，只能在自己的评测集上试。

## 学习者的落地路径

1. **先找现成 SFT 数据集**：在 Hugging Face 或魔搭搜同任务的数据卡，看许可、看样例、看评测口碑。
2. **自建 100–1000 条精标数据**：从真实业务问题出发，覆盖边界情况，比公开数据更贴合场景。
3. **用合成扩量**：种子数据 + 强模型扩写，再人工抽检一部分样本，错误率高的批次整批丢弃。
4. **留出评测集**：训练前就切分，且评测集不能与训练集有重叠样本，否则指标虚高。
5. **记录来源**：每条数据记来源、许可、采集日期，后续商用审查时才拿得出证据。

## 一句话主线

训练数据按阶段分四种：**预训练靠公开语料，SFT 靠精标与合成，偏好靠人工排序，RLVR 靠可判分题库**；开放平台解决"有没有"，许可与清洗解决"能不能用、好不好用"——真正稀缺的从来不是网页，而是可授权的高质量示范数据。
