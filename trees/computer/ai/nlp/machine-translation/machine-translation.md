# 机器翻译（Machine Translation）

机器翻译是把文本从一种自然语言自动转换到另一种——AI 历史最悠久的应用之一，自动翻译的梦想从 1950 年代就驱动着 AI 研究。它也是 Transformer 的"出生地"：2017 年的《Attention Is All You Need》本身就是一篇翻译论文。

## 技术演进四代

| 世代 | 时期 | 做法 | 弱点 |
|---|---|---|---|
| **规则式（RBMT）** | 1950s–2000s | 手写转换规则与词典 | 脆弱、覆盖差 |
| **统计机器翻译（SMT）** | 2000s–2014 | 从平行语料学词/短语对齐，短语表 + 语言模型 + 重排序，MERT 调 BLEU | 词序错乱、长句语义纠缠；Google Translate 初版用 SMT |
| **神经机器翻译（NMT）** | 2014–2022 | 端到端 encoder-decoder + attention，子词 BPE | 上下文窗口短，段落/文档一致性差；领域适配需单独训练 |
| **LLM 翻译** | 2022–今 | 通用指令模型零样本翻译 | 低资源语言、成本与延迟 |

关键里程碑：

- **2014**：RNN encoder-decoder（Cho）、seq2seq with LSTM（Sutskever，WMT'14 En-Fr 34.8 BLEU）——端到端学习。
- **2014–2015**：Bahdanau attention 打破固定向量瓶颈——**注意力最初就是为翻译发明的**，之后重组了整个领域。
- **2016**：BPE 子词（Sennrich）实现开放词表；GNMT 上线 Google，相比短语式平均错误减少约 60%；多语言 NMT + 零样本翻译（Johnson）。
- **2017**：Transformer（Vaswani）——去掉循环使训练并行，WMT En-De 28.4 BLEU、En-Fr 41.8，成为标准架构；DeepL 同年发布。
- **2019–2022**：大规模多语言 NMT——mBART、M2M-100（100 语言、非英语中心）、NLLB-200（200 语言、MoE + 数据挖掘、开源，含 FLORES-200 基准），未见语言对的零样本迁移成真。
- **2023–今**：GPT 类 LLM 在高资源语言对上与专用系统持平或超越；WMT24/WMT25 把 LLM 与商用系统一起评测，并转向**文档级**、难度采样测试集。

## 现代翻译如何工作

源文本先子词分词（多为 BPE，缩小词表同时保留稀有词素）→ embedding 映射为高维向量 → 多层 encoder（多头注意力学习 token 关系、捕捉长距离依赖）→ 压缩成表示 → decoder 以 masked self-attention 逐 token 生成目标，通过 cross-attention 关注源句相关位置。训练时对人工参考最小化交叉熵，需数百万句对与数周 GPU。

**NMT 胜过 SMT 的关键**：上下文化——英文 "bank" 在提到 water/flood 时法语翻成 "rivière"，SMT 需显式规则或大上下文；子词分词让芬兰语、土耳其语等黏着语能生成未见复合词。WMT 2022 新闻翻译上 NMT 比 SMT BLEU 高 6–8 分，人工在流畅度上 78% 偏好 NMT。

## 数据与多语言

- 双语平行语料（英法/英德/英中）提供数千万句对；挖掘的网页数据扩展到数万亿 token。
- **回译（back-translation）**：把单语目标文本翻回源语，造合成平行对——教科书级增强手段。
- 大规模多语言预训练模型（mBERT、XLM-R、mT5）学习跨语言共享表示，实现**零样本跨语言迁移**：高资源对训练的模型可翻低资源语言。
- 在 MT 里，**领域内数据胜过规模**：通用模型翻临床笔记或专利权利要求，不如用 5 万句对领域数据微调的小模型。

## 评测指标

| 指标 | 做法 | 特点 |
|---|---|---|
| **BLEU**（Papineni 2002） | 改进的 n-gram 精度 + 简短惩罚 | 快、确定性、需参考；默认 20 年，但与人工判断相关 imperfectly，对高质量系统尤其失准 |
| **chrF / chrF++** | 字符级 n-gram，更重召回 | 对形态丰富语言（芬兰、土耳其、捷克）优雅降级——一个错后缀会让 BLEU 词匹配归零；应与 BLEU 并列或替代 |
| **COMET / BLEURT** | 神经指标，直接在人工评分上训练 | 与人工判断相关性远高于 BLEU，WMT 标准 |
| **MQM / 人工** | 人工标注错误跨度 | 金标准但慢且贵；文档级评测发现孤立句评分高估"人类平价" |

**质量估计（QE）**：无参考评测——训练二级模型预测 HTER（人工目标翻译编辑率），直接从源文与译文的神经表示预测质量分数，给每句打正确概率，把低置信译文路由给人工译后编辑。NMT 引擎更新或领域变化时 QE 模型需重校准，否则漂移。

## LLM 时代的翻译

LLM 把翻译当作通用语言能力的副产品，无需 MT 专项训练。三大优势：**长上下文**（10 万–100 万 token，文档级一致）、**提示驱动的领域/语气控制**（"用法律语气""当营销文案"，无需微调）、**自然语言结构保留**（代码、表格）。两大劣势：**成本**（NMT 的 5–50 倍/字符）与**延迟**（NMT <100ms，LLM 数秒）。

LLM 的相对优势在上下文类：文档级一致、遵守风格指令、使用提供的术语表、解释歧义——这些 encoder-decoder NMT 完全做不到。弱点在低资源语言（NLLB 等专用模型仍领先）与成本。

**2026 生产实践是混合路由**：默认走便宜模型（小双语 Marian 模型在固定领域单语言对上每 FLOP 质量最优——75M 参数、毫秒级），重要内容走 LLM；200 语言广度尤其低资源用 NLLB。三代共存：SMT 留在嵌入式设备，NMT 是大批量主力，LLM 填补质量决定性场景。

## 持续挑战

- **低资源语言**：世界数千语言无平行语料；NLLB 覆盖的约 180 种非头部语言输出常只够抓大意、不够发表。
- **领域适配**：医疗、法律需专门词汇与措辞；术语表增强（glossary-augmented）翻译正在兴起但缺系统研究。
- **惯用语与文化**："it's raining cats and dogs" 直译在多语言里荒谬；敬语、语域、隐喻、文化含义处理差且少被测量。
- **语码混合**：单句混多种语言。
- **文档级一致性**：跨段落的语域与术语一致。
- **无参考质量估计、自适应翻译**（从译者会话内编辑中学习）是 2026 前沿。
- **语义奖励 RL**（COMET 风格）可在无灾难性遗忘下把 LLM 扩展到低资源语言；DPO/CPO 正在替代 SFT 用于 LLM-MT。
