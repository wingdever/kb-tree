# 人工智能（AI）

人工智能是让机器**感知、推理、学习与行动**的学科与实践，目标是完成通常需要人类智能的任务。它是「计算机」学科下的一个主要分支，本文件说明它研究什么、包含哪些领域。

## 六大领域

| 领域 | 回答的问题 |
|---|---|
| **agent** | 怎么设计、构建、评估、部署 Agent；multi、MCP、LangGraph、安全、obs |
| **rag** | 怎么让模型检索自有知识；记忆机制与 Agentic RAG |
| **model** | 模型怎么分词、预训练、训练、微调、distill、压缩、部署、eval；multimodal 与 RL |
| **nlp** | Transformer 架构、意图识别、机器翻译、世界信息结构、语言模型谱系与应用 |
| **world-model** | 世界模型如何预测环境状态以规划；JEPA/生成式/3D/模型基 RL 与具身智能 |
| **api** | 各厂商工具调用 API 的具体字段、JSON 形状、控制参数与错误处理 |

## 横向主题

- **RSI（递归自我改进）**：系统用当前能力改进决定未来能力的组件，再用改进后的版本继续改进；它讨论的是能力复利与生态壁垒，不属于上面六个工程领域中的任何一个单独领域。

## 一句话主线

从让模型"会思考行动"的 Agent，到为它提供知识的 RAG 与模型工程，再到理解语言的 NLP、预测物理世界的世界模型，以及把所有能力接成工具的 API 规范——六个领域共同构成当代 AI 工程版图。各领域按"总览 md + 子知识点子树"独立展开，可按需深入。
