# Agent 互操作与接口

这一组回答"Agent 怎么接外部世界"。工具决定它能做什么，协议决定它跟谁对话，技能与渠道决定能力如何被打包和触达——四者合起来构成 Agent 的外部接口。

## 一句话主线

工具定义能力、协议定义对话对象、技能打包知识、渠道决定触达方式——按"对面是谁"选接口，别把协议混用。
