# Agent 数据连接

Agent 的“智能”很容易被看见，Agent 的“接通”却最容易坏。案例里真正决定成败的不是总结写得多好，而是**抓取插件能不能拿到正文、代码节点能不能拼出正确 JSON、飞书插件能不能写进正确的列**。

数据连接要解决四件事：拿得到、对得上、写得进、错得起。

## 插件：外部能力的适配器

插件是把外部系统包装成节点可调用的工具。它有三层契约：

- **输入**：参数名、类型、是否必填、默认值；
- **输出**：字段名、类型、嵌套结构；
- **失败**：错误码、错误信息、是否可重试。

案例的抓取插件输入一个 URL，输出 `title`、`content` 等字段；保存插件输入 `app_token`、`records`，输出 `log_id`、`msg`。下游不能假设“插件一定成功”，要把空结果、错误码、超时都当成正常分支。

选插件时优先看文档：参数说明是否清楚、输出是否结构化、是否有调用配额、是否支持你要的权限模式。文档缺失的插件，会把调试成本转移到你身上。

## 代码节点：做确定性的转换

代码节点适合无状态的数据变换：改字段名、拼数组、做类型转换、过滤空值、截断超长文本。它不适合承载需要事务、持久化或复杂权限的外部写入。

案例用代码节点把四个字段组装成飞书要求的结构：

```json
{
  "record_info": [
    {
      "fields": {
        "title": "...",
        "summary": "...",
        "tags": "...",
        "content": "..."
      }
    }
  ]
}
```

这里的关键不是代码多复杂，而是**形状对齐**：外层是数组，元素有 `fields`，`fields` 里的键必须和表格列名一致。形状不对，接口就会拒绝或写错列。

代码节点要写输入输出声明，并在代码里做防御：

- 字段缺失时给默认值或抛错；
- 类型不对时转换或拒绝；
- 内容过长时截断并记录；
- 不要把令牌、密钥硬编码在代码里。

## JSON 字段映射

跨系统连接的本质是字段映射。要做一张表：

| 上游字段 | 下游字段 | 类型 | 转换规则 |
|---|---|---|---|
| `title` | `fields.title` | string | 去空白、截断 |
| `summary` | `fields.summary` | string | 保留原文 |
| `tags` | `fields.tags` | string | 数组转逗号分隔 |
| `content` | `fields.content` | string | 超长截断或分段 |

映射表要在搭建前写，不要边调边猜。字段名、大小写、嵌套层级、必填/可选，任何一处不一致都会表现为“写入失败”或“写进去但列是空的”。

## 授权与权限

案例里的飞书写入需要 `app_token` 与表格权限。真实系统还要处理：

- 令牌从哪来、存在哪、多久轮换；
- 权限是否最小：只写指定表，不读无关数据；
- 多用户场景下，是平台级令牌还是用户级授权；
- 令牌是否可能出现在日志、提示词、错误信息里。

一个常见错误是把令牌写进提示词让模型“记住”。模型不需要知道令牌；令牌应该由平台凭证或代码环境注入。

## 幂等与重试

写入外部系统必须考虑重复：

- 同一个 URL 被提交两次，是否会产生两行？
- 插件超时但实际写成功，重试会不会重复？
- 批量写入部分成功，怎么记录成功与失败？

做法：

- 用业务键做幂等，例如 URL + 用户 ID + 日期；
- 写入前查重，或写入后用唯一键校验；
- 只对瞬时错误重试，权限错误与 schema 错误不重试；
- 返回结果里区分“成功、失败、部分成功”。

## 失败可诊断

数据连接的失败要让用户和运维都能看懂：

- 对用户：说清是哪一步失败、能做什么（重试、换链接、检查权限）；
- 对运维：保留节点输入、输出、错误码与耗时，能复现；
- 对流程：失败走显式分支，不要吞掉后返回一句“已完成”。

案例的结束节点会把保存结果返回给用户；如果保存失败，应该返回失败原因，而不是继续展示摘要，让人误以为已经入库。

## 边界

- 能走 API 就不走页面抓取；页面结构、反爬与登录态会让抓取插件随时失效。
- 插件配额与限流要提前确认；批量任务要分批、排队、可恢复。
- 代码节点不是安全边界：它运行在平台环境里，敏感信息仍要通过平台凭证管理。
- 飞书多维表格适合轻量素材库与人可读台账，不适合高并发事务系统。

## 一句话主线

**插件负责接通，代码负责转换，字段映射负责对齐；授权最小化、写入幂等、失败可诊断，数据连接才算真正可用。**
