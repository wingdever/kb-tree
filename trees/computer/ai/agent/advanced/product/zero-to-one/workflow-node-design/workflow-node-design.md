# 低代码工作流节点

工作流是把流程图变成可执行管线的地方。它的基本单位不是“提示词”，而是**节点**：每个节点有输入、处理逻辑、输出和失败语义。

这篇实战里的工作流很短：开始 → 抓取内容 → 大模型总结 → 转 JSON → 保存到飞书 → 结束。短，但已经把工作流的核心契约都演了一遍。

## 节点类型

低代码平台常见的节点类型：

| 类型 | 作用 | 典型用途 |
|---|---|---|
| 开始 | 定义输入变量 | 接收 URL、表单、消息 |
| 结束 | 定义返回方式 | 返回文本或结构化变量 |
| 插件 | 调外部能力 | 抓网页、写表格、发消息 |
| 大模型 | 总结、分类、抽取、生成 | 摘要、标签、判断 |
| 代码 | 数据转换与清洗 | 拼 JSON、改字段名、算格式 |
| 选择器 | 条件分支 | 成功/失败、类型分流 |
| 循环 / 批处理 | 对列表逐项处理 | 批量抓取、批量写入 |
| 变量聚合 | 合并多路结果 | 分支后汇总 |
| 输入 / 输出 | 显式暴露中间数据 | 子工作流、调试 |

节点类型不是越多越好。一个节点里塞“抓取 + 总结 + 写库”，失败时无法定位；拆成三个节点，代价是多几次编排，换来的是可观察、可重试。

## 开始与结束

开始节点负责把外部输入变成工作流变量。案例里定义了一个 `url` 变量，智能体调用工作流时从用户消息中提取并传入。

开始节点要写清：

- 变量名与类型；
- 是否必填；
- 默认值与描述；
- 输入不合法时怎么拒绝。

结束节点负责把内部结果返回给调用方。有两种常见方式：

- **返回变量**：输出 JSON，适合被其他工作流、卡片或 API 消费；
- **返回文本**：直接作为对话回复，适合面向用户的简单场景。

案例用返回文本，把保存结果、标题、摘要、标签拼成一句人可读的回复。如果这个工作流要给别的系统调用，就应该返回结构化变量，而不是一段话。

开始与结束之间必须有连线。没有连线的图只是画布上的几个框，不会执行。

## 变量引用

节点之间靠变量传递，不靠“模型记得上文”。每个节点的输出都是命名变量，下游按名字引用：

- 抓取节点输出 `title`、`content`；
- 大模型节点输入 `title`、`content`，输出 `summary`、`tags`；
- 代码节点输入四个字段，输出 `record_info`；
- 保存节点输入 `app_token`、`records`，输出 `log_id`、`msg`。

变量引用要检查三件事：名字是否一致、类型是否匹配、空值是否处理。最常见的线上错误不是模型不会，而是下游拿到的字段名和上游输出的不一样。

## 分支与失败路径

工作流不能只有成功路径。至少要显式处理：

- 抓取失败：页面不存在、反爬、超时；
- 模型失败：输出不是合法 JSON、字段缺失；
- 写入失败：令牌过期、表格权限不足、接口限流；
- 输入不合法：不是 URL、空消息、超长文本。

每条失败路径要有去向：重试、返回错误、转人工、跳过并记录。低代码平台通常提供选择器或错误分支；没有显式分支时，失败会被吞成一句“运行失败”，用户不知道下一步。

## 单节点测试

不要等整条链路搭完才测试。每个节点单独跑一次真实输入：

- 抓取节点：给一个真实 URL，确认标题与正文非空；
- 模型节点：给一段真实文章，确认 JSON 字段完整；
- 代码节点：给一组真实字段，确认输出结构符合下游要求；
- 保存节点：用测试表格，确认写入后字段对得上。

单节点测试能把“模型问题”和“接线问题”分开。整条链路一起测，失败时很难判断是哪一段。

## 工作流与智能体的分工

工作流是固定管线：步骤和分支在开发期写死，适合输入稳定、流程可列全的任务。智能体是入口与调度：它识别意图、选择工具或工作流、组织回复。

案例里，智能体负责“接收链接、调用素材收集工作流、把结果说给用户”；工作流负责“抓取、总结、写表”。把两者混在一起，会让“谁决定下一步”变得不清楚。

一个智能体可以挂多个工作流：文章走文章收集，视频走视频收集，播客走转写流程。路由依据应该是输入类型或明确条件，不是让模型自由猜。

## 边界

- 工作流适合确定性任务；开放式探索、多步决策、动态工具选择，才需要更自主的 Agent。
- 低代码节点有执行时长、配额与并发限制；长任务要拆分、异步或排队。
- 代码节点不是万能胶：它适合无状态转换，不适合承载需要持久化与事务的外部写入。
- 节点测试通过不代表端到端通过；还要测脏输入、并发与权限失效。

## 一句话主线

**工作流用节点承载步骤，用变量承载数据，用连线承载顺序，用分支承载失败；每个节点都要有输入、输出和失败去向，整条链才可执行、可定位、可重试。**
