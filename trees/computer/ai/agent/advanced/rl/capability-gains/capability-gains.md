# Agentic RL 功能增强

Agentic RL 不是给 Agent 加一块新知识，而是用环境反馈改变它的行为分布：同样会说话，但更会在多步任务里选动作、用工具、从失败里恢复。增强不是全面的，它主要发生在“可重复执行、结果可判定”的功能上。

## 增强的是策略，不是知识

- SFT 学的是“照着示范做”；Agentic RL 优化的是“做了之后结果好不好”。
- RL 改变的是动作概率：何时调用工具、传什么参数、失败后重试还是换路。
- 事实型知识仍应交给 RAG；RL 不负责把新事实稳定写进权重。
- 没有环境与验证器，RL 只能优化“像不像”，很难优化“对不对”。

## 六类主要增强

### 工具调用策略

- 学会判断“该不该调用工具”，而不是每步都调用或从不调用。
- 学会选工具、填参数、读返回结果，并在报错时换工具或修参数。
- 这类功能最容易见效，因为工具调用成功与否可以被沙箱稳定判定。

### 多步规划与执行

- 把任务拆成有顺序的步骤，控制轮次与预算，避免无效循环。
- 学会在中间结果出现后调整计划，而不是死守初始方案。
- 只有最终结果可验证时，规划能力才会被奖励真正拉起来。

### 失败检测与自我纠正

- 从工具报错、测试失败、空结果中识别“这条路走不通”。
- 学会重试、回退、换策略，而不是重复同一个错误动作。
- 如果奖励只看最终答案，过程里的纠正不会被单独奖励；需要过程信号或课程设计。

### 长周期状态管理

- 在多轮任务里记住目标、约束与已完成步骤，减少上下文漂移。
- 学会在合适的时机收尾，避免无限追问或过早结束。
- 长周期任务的信用分配仍难；轨迹级奖励是可用默认，步级信号仍是研究问题。

### 成本与效率取舍

- 学会用更少工具调用、更短轨迹达到同样结果。
- 在成功率、延迟与成本之间做取舍，而不是盲目堆动作。
- 这需要奖励里显式惩罚冗余动作；否则 RL 只会学会“多做多错也能碰对”。

### 安全与权限边界

- 在奖励或验证器包含安全约束时，学会拒绝越权动作、避开危险工具。
- 若安全只在提示词里说、奖励里没有，RL 可能学会绕过它。
- 高风险场景要把权限、审计与回滚放在环境层，不能只靠策略自觉。

## 弱增强或不增强的功能

- **事实知识**：RL 不是知识注入手段；新事实优先 RAG 或继续预训练。
- **开放风格与同理心**：没有偏好数据时，规则奖励说不清“哪种语气更好”。
- **不可验证的长周期策略**：模拟器覆盖不到真实分布时，RL 学到的是模拟器偏好。
- **多 Agent 协作**：信用分配与环境稳定性更难，当前更多是研究与小规模实验。
- **分布外迁移**：训练环境越窄，越容易过拟合到验证器；多样化环境才有泛化。

## 增强成立的条件

1. 环境可重复：同一动作能得到稳定反馈。
2. 结果可判定：验证器能区分“真解决”和“看起来解决”。
3. 任务有可学习信号：模型偶尔能做对，RL 才有梯度可推。
4. 奖励形状合理：稀疏奖励要配中间信号，稠密奖励要防奖励黑客。
5. 评测独立：训练验证器与上线评测分开，否则只是拟合同一把尺子。

## 一句话主线

Agentic RL 增强的是“在环境里做对”的策略能力；验证器决定它能增强什么，也决定它会在哪里学会作弊。
