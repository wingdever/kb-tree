# 多智能体系统

多智能体不是默认选项。**单 Agent + 工具是基线**，是每个设计都应拿来对比的诚实起点。只有当单个工具齐备的 Agent 不够用时，才拆分。

本目录把多智能体拆成 8 个子知识点，每个自成一个目录、目录内放同名介绍 md。

## 一句话主线

先判断单 Agent 是否真的不够（设计判断），选一个架构模式（架构模式），确定谁拥有对话与控制权（编排器与执行器），设计 Agent 之间怎么传信息（交接与通信，跨组织时用标准协议），用五大模块保证可靠（构建模块），需要处理分歧时用共识机制（共识与决策），并对照 MAST 提前防失败（失效模式），最后落到具体框架（框架实现）。
