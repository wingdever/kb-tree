# 阿里云百炼新人额度

百炼的免费额度是国内目前覆盖模型最广的一份：不是给一个大池子，而是**每个模型单独给一份**，所以账面总量看起来很大，实际能用的宽度取决于你愿意试多少个模型。

## 给的是什么

首次开通百炼服务后，系统自动为各模型发放免费推理额度，主流模型每款约 100 万 token，覆盖 70 多款模型，合计超过 7000 万 token。

关键在"按模型切分"：

- 额度按模型（含同一模型的不同快照版本）独立计算，互不共享。
- 某个模型额度用尽后，系统**不会**自动切到另一个有额度的模型，必须自己改调用参数里的模型名。
- 因此实际策略是"逐模型试跑"，而不是把它当成一个大水池。

## 领取条件与生效范围

| 条件 | 说明 |
|---|---|
| 账号 | 阿里云账号完成个人或企业实名认证 |
| 资格 | 仅首次开通百炼的新用户；同一实名主体下重新注册不能再领 |
| 地域 | 仅华北 2（北京）地域的模型实时推理享受免费额度，其他地域没有 |
| 生效 | 开通即自动发放，无需手动领取、无需绑支付方式 |
| 账号共享 | 主账号与 RAM 子账号共享同一份额度 |

## 时效与失效

- 有效期 90 天，从开通服务、模型发布或模型申请通过三者中**较晚**的时间起算。
- 有效期内无论是否使用都在计时，过期后剩余额度自动失效，不支持补发、延期或重置。
- 长度上够跑完一轮原型验证，不够做长期 demo；把"什么时候开通"当成一个决策，而不是随手点开。

## 抵扣规则

- 抵扣顺序：免费额度 → 资源包 → 节省计划 → 按量付费。
- 只抵扣实时推理调用，不覆盖 Batch 批量调用、模型调优、模型部署、自定义模型、知识库构建、存储等。
- 已认证用户额度用完后会自动转按量付费；控制台可以打开"免费额度用完即停"，避免意外扣费。

## 最容易踩的三个坑

1. **专属密钥不抵扣**。`sk-sp` 开头的 Token Plan 专属密钥调用不消耗免费额度——想用免费额度试模型，必须用普通 `sk` 开头的通用 API Key。
2. **以为额度可以互相借**。换模型不会自动切额度，脚本里写死一个模型名，跑到额度见底就报错。
3. **忽略地域**。把 endpoint 配到非北京地域，调用成功但账单照走，免费额度纹丝不动。

## 怎么用才值

- **横向比模型**：同一批提示词分别打 Qwen-Max、Qwen-Plus、Qwen-Flash，用每模型那份百万 token 做能力对照，这比读榜单可靠。
- **先定分层线**：用免费额度跑完旗舰与轻量两档，找出"便宜模型够用"的任务边界，再决定付费档位。
- **写死额度开关**：在脚本里记录每个模型的已用量，接近上限时切模型或降级，而不是等报错。

## 一句话主线

百炼的免费额度是**按模型发放的试用装**：宽度靠多模型，深度只有每款百万 token 和 90 天，它适合把选型做完，不适合把服务跑起来。
