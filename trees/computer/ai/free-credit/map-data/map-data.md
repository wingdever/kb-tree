# 大陆地图数据的免费来源

"免费地图数据"要先问用途：是要一张能公开引用、带审图号的边界图，还是要能调接口的在线底图，要能下钻的行政区 GeoJSON，还是要道路与 POI 矢量。四类来源的授权方式完全不同，混用会同时踩测绘合规和坐标系两个坑。

## 权威底图与行政边界

- **自然资源部标准地图服务**：提供全国、省、市三级标准地图，JPG 与 EPS 格式，每张带审图号。这是唯一可以直接公开引用的法定边界底图，做汇报、论文、宣传物料优先用它。
- **天地图**：国家地理信息公共服务平台，注册开发者 key 后可调用在线底图、地名检索与逆地理编码，个人开发者有免费配额。底图坐标系为 CGCS2000，不存在 GCJ-02 的偏移。
- **全国地理信息资源目录服务系统**：可查 1:5 万、1:25 万基础地理信息数据的目录与获取方式，部分成果对公众开放，适合做需要更高精度的专业用途。
- **DataV.GeoAtlas**：免费下载省、市、区县行政边界 GeoJSON，适合做地图下钻与可视化。它只解决"画出边界"，边界本身的法律效力仍以标准地图为准。

## POI 与检索接口

高德开放平台、百度地图开放平台、腾讯位置服务都向个人开发者提供免费日配额，Web 服务 API 与前端 JS API 都可申请 key。

条款里三条限制最关键：**不得缓存或转售瓦片与 POI**、不得把数据做成离线底图再分发、公开上线的地图必须标注审图号并使用具备测绘资质的服务商。个人练手无碍，做成产品就要转企业授权。

## 开源与科研数据

- **OpenStreetMap**：ODbL 许可，可商用但须署名，衍生数据要以相同许可共享。大陆的道路与 POI 由志愿者贡献，城市主干道可用，新建道路与乡村细节常滞后；Geofabrik 提供中国区域 extract，按周更新。
- **地理空间数据云**：Landsat 系列、SRTM、ASTER GDEM 等遥感与高程数据免费下载，适合做影像底图与地形分析。
- **全球免费高程**：Copernicus DEM、NASA SRTM、ALOS AW3D30 均为 30 米级，覆盖中国大陆，可直接用于坡度、等高线与三维地形。
- **国家统计局**：行政区划代码与统计口径，配合边界数据做人口、经济专题图。

## 坐标系与偏移

| 坐标系 | 谁在用 | 特征 |
|---|---|---|
| WGS84 | GPS、OSM、多数国际数据 | 全球统一，无偏移 |
| GCJ-02 | 高德、腾讯等国内图商 | 国测局加密偏移，与 WGS84 相差数百米 |
| BD-09 | 百度 | 在 GCJ-02 上再偏移一次 |
| CGCS2000 | 天地图、国家基础测绘成果 | 国家大地坐标系，近似 WGS84 但不完全等同 |

混用坐标系的典型症状是"点位整体平移几百米"。做法是统一到一个坐标系再叠加，转换要用成熟的转换库，不要手写经验公式。

## 合规红线

- **公开地图必须有审图号**：边界不能自行拼接，标准地图服务下载的版本可直接使用；自制专题图涉及国界、行政区划时，要送审或改用标准底图。
- **不能抓商业瓦片自建服务**：抓取高德、百度、腾讯的瓦片或 POI 建离线服务，既违反服务条款，也涉及测绘资质问题。
- **导航电子地图是特许业务**：制作导航电子地图需要相应测绘资质，个人与小团队不具备。
- **敏感要素不存在于公开数据**：军事设施、精确坐标、未公开测绘成果都不在公开数据集里，也不应尝试补齐。
- **数据出境**：高精度测绘成果的出境受限制，把境内采集的地理数据传到境外处理前要先评估。

## 怎么选

1. **要在文档、论文、宣传物料里放一张中国地图**：标准地图服务下载，带审图号直接用。
2. **要做在线底图与地名检索**：天地图 key，配额内免费；需要商业级 POI 再评估高德或百度。
3. **要做省市区下钻的可视化**：DataV.GeoAtlas 的 GeoJSON，配合统计口径数据。
4. **要做路网分析或开源项目**：OSM extract，注意 ODbL 的署名与同许可义务。
5. **要做地形、影像、坡度**：地理空间数据云与全球 DEM，按分辨率需求选 30 米或更高。

## 一句话主线

大陆的免费地图数据分四种角色：**法定边界看标准地图服务，在线底图看天地图，可视化下钻看 DataV，路网与地形看 OSM 和遥感 DEM**；许可与审图号决定能不能公开用，坐标系决定点位对不对得上。
