# CodeBuddy Free

腾讯云 CodeBuddy 的 Free 档是长期免费层，官方订阅文档给 100 积分/月，并在活动期按活跃日送 30 积分；新用户另送 250 积分。


## 免费额度

Free：100 积分/月；每日活跃奖励 30 积分（限时，活动日最多一次）；新用户注册 250 积分（14 天有效）；Pro 7 天试用 500 积分。中国定价页另显示“体验版每月 500 积分”，与订阅文档口径不完全一致，引用时要注明页面。

## 接入方式

CodeBuddy 有 CLI、Agent SDK（TypeScript/Python）与 OpenAPI；Free 档可通过 SDK/CLI 登录态调用，是最适合自有 Agent 接入的 C 端 Coding Agent 之一。

## 限制与风险

Free 积分少，且基础/加赠积分当月有效；免费档模型走 Auto 路由；SDK/CLI 自动化是否消耗同一份额度要以条款为准；中国区与海外区定价不同。

## 适合谁

适合个人开发者做低频 Agent 调用与集成实验；生产应走 Pro/Team 或 TokenHub Coding Plan。
