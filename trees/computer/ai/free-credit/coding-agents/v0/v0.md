# v0 Free

v0 是 Vercel 的生成式 UI/应用 Agent；Free 档按美元 credits 计量，并有每日消息上限。


## 免费额度

Free 每月 $5 credits；每天 7 条消息；新用户可能是一次性 $5 而不是每月续发，官方文档写“current offer”，需看账号账单页；API 权限在付费档。

## 接入方式

主要是 Web UI；免费档没有 API，付费档才有 v0 API；接入自有 Agent 只能走浏览器自动化，属于弱接入。

## 限制与风险

$5 额度很小；每天 7 条消息；新用户一次性额度不续发；免费档无 API。

## 适合谁

适合生成 React/Next.js UI 草稿；不适合批量或后端集成。
