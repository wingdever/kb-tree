# Google Antigravity Free

Antigravity 是 Google 在 2026 年整合 Gemini Code Assist 与 Gemini CLI 后的 Agent 平台；个人 Free 档 $0，给按周刷新的基础 Agent 额度。


## 免费额度

官方写“有意义的每周基础额度”，未公布固定条数；额度按 Agent 实际工作量扣减，复杂任务消耗更多；第三方实测约 300 credits/月（2026-07），仅作参考，不是官方承诺。

## 接入方式

官方入口包括桌面 App、CLI `agy`、IDE 扩展与 Python SDK；这是 Free 档里少见的“官方 SDK + CLI”组合，适合自有 Agent 做适配。

## 限制与风险

额度按周刷新且受容量影响，无法精确预算；Workspace 账号不享受个人档；模型可用性随容量变化；免费档不是 SLA。

## 适合谁

适合替代 Gemini CLI 的个人开发者，做中等频率 Agent 任务；生产仍需 Pro/Ultra 或企业档。
