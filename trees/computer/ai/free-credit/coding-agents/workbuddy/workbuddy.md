# WorkBuddy Free

WorkBuddy 是腾讯的办公 Agent，带代码补全与自动任务；国内体验版每月 500 积分，国际版 Free 为 100 积分/月加每日活跃奖励。


## 免费额度

国内体验版：每月 500 积分，5,000 次代码补全（限免无限），3 个自动任务（限免 99），5 个项目，5GB 资料库。国际版 Free：100 积分/月 + 30 积分/天（限时），新用户 250 积分。

## 接入方式

WorkBuddy 开放平台提供 OAuth 2.1 的 Open API，第三方应用可在用户授权后调用；桌面端本身不是 Coding CLI。

## 限制与风险

它是办公 Agent，不是纯 Coding Agent；积分与自动任务额度有限；免费档模型走 Auto；Open API 的权限范围与可调用能力要以开放平台为准。

## 适合谁

适合办公场景顺带做代码任务；若目标是纯代码 Agent，优先 CodeBuddy 或 Codex。
