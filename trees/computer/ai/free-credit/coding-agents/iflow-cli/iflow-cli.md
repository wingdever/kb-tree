# iFlow CLI

iFlow CLI 是阿里心流团队的终端 Agent，官方定位“面向个人用户永久免费”，并内置多家国产模型的免费托管额度。


## 免费额度

个人用户免费；内置 Kimi K2、Qwen3 Coder、GLM 等模型，官方未公布固定请求条数；按平台限流与模型可用性动态调整；支持 MCP、SubAgent、Headless 模式。

## 接入方式

官方 CLI + IDE 插件 + MCP；开源客户端可直接子进程调用，认证用 iFlow 账号或 API Key；Headless 模式适合自有 Agent 包装。

## 限制与风险

免费模型名单与限流会变；没有公开 SLA；个人免费是否覆盖商业用途要以条款为准；复杂任务消耗平台资源，可能被限流。

## 适合谁

适合个人开发者做日常 Coding Agent；接入自有 Agent 的成本低，但不建议承载商业生产。
