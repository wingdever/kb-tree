# JetBrains AI Free

JetBrains AI 的 Free 档给少量 AI credits 与无限行内补全；它更像“IDE 自带 AI + 少量 Agent 额度”，不是独立 Coding Agent。


## 免费额度

每 30 天 3 AI credits（1 credit ≈ $1 AI 用量）；AI 补全不限次；首次激活送 30 天 AI Pro 试用（10 credits）；AI Free 在部分 IDE 需 Ultimate/Pro 订阅才可用。

## 接入方式

入口是 JetBrains IDE 与 JetBrains Air；没有公开 Agent API；接入自有 Agent 只能走 IDE/ACP 或 UI 自动化，属于弱接入。

## 限制与风险

3 credits 只够极少量的云端 Agent 调用；Junie 等 Agent 能力在免费档受限；Android Studio 不提供 AI Free；credits 不累积。

## 适合谁

适合 JetBrains 用户顺手用补全；不适合把 Agent 当免费算力池。
