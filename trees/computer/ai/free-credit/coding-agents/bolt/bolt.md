# Bolt.new Free

Bolt.new 是浏览器里的 Vibe Coding Agent；免费档按 token 计量，额度在同类产品里较大。


## 免费额度

每月 1,000,000 tokens；每日上限 300,000 tokens；每日额度不累积；免费档带 Bolt 品牌、10MB 上传、1 个可发布项目等限制。

## 接入方式

主要是 Web UI，没有公开的免费 Agent API；接入自有 Agent 只能走浏览器自动化，属于弱接入。

## 限制与风险

按 token 计量且项目越大越费；每日 300K 上限；免费档带品牌与上传限制；无 API/SLA。

## 适合谁

适合快速做原型与小应用；不适合接入自有 Agent 做后台。
