# Windsurf Free

Windsurf 的 Free 档是长期免费层，给少量 premium prompt credits；用完后仍可用不消耗积分的模型与无限 Tab。


## 免费额度

每月 25 prompt credits；Windsurf Tab 无限；Previews 无限；每天 1 次 App Deploy；2 周 Pro 试用给 100 prompt credits。

## 接入方式

目前主要是 IDE 内 Cascade Agent，没有公开的 Agent API；接入自有 Agent 只能走桌面/浏览器自动化，属于弱接入。

## 限制与风险

25 credits 只够少量多步任务；premium 模型耗尽后切到零积分模型，能力下降；无公开 API，UI 自动化易受版本影响。

## 适合谁

适合个人体验 Cascade 与 Tab；不适合生产集成。
