# Huawei CodeArts Free

华为云码道 CodeArts 代码智能体在 2026 年 11 月切到积分制；个人体验版免费，给月度积分与每日赠送积分。


## 免费额度

官方定价表：体验版 ¥0，每月基础 0 积分、每日赠送 50 积分；开发者开通页写“每月赠送 500 积分”。两处口径不同，实际以账号权益页为准。进阶能力（本地 AgentTeam、云端定时任务）限时体验 14 天。

## 接入方式

支持 AI IDE、CLI/TUI、JetBrains 与 VS Code 插件；CLI 可被自有 Agent 调用，但免费额度主要用于体验。

## 限制与风险

月度/每日积分口径不一致；免费档并发 3 个会话、3 个 Agent Space；知识空间 500MB、代码库索引 5,000 文件；进阶能力仅 14 天。

## 适合谁

适合华为云生态个人开发者体验 Agent；不适合长期免费承载生产。
