# Amazon Q Developer Free

Amazon Q Developer 有永久免费层，覆盖 IDE 插件与 CLI 的 Agent 对话和 Agent 编码；Pro 才提高额度与企业管理能力。


## 免费额度

每月 50 次 Agent 请求（Q&A 对话 + Agent 编码合并计算）；Java 升级每月 1,000 行代码；AWS 资源查询每月 25 次/账号；IDE 免费额度只对 Builder ID 用户开放。

## 接入方式

官方 CLI 可被上层 Agent 调用，认证用 AWS Builder ID/IAM；50 次额度适合低频任务；IDE 插件计划于 2027-04-30 停止支持，官方建议迁移 Kiro。

## 限制与风险

50 次很容易耗尽；免费档不含 IP  indemnity；组织席位用户不适用个人免费；IDE 插件有明确停服日期。

## 适合谁

适合 AWS 生态内的轻量 Agent 任务与 Java 升级；不适合长期产品后端。
