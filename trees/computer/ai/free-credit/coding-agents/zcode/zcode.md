# ZCode Free Trial

ZCode 是智谱的 Agentic Coding 桌面端；免费部分是 5 天 Start Plan 试用，不是长期免费层。


## 免费额度

新用户 Start Plan：5 天，每天 800 万 tokens（GLM-5.4 300 万 + GLM-5.3-Flash 500 万）；试用到期后停止，不是每日长期额度；另有 300M GLM-5.3-Flash 的限时活动，需按活动规则领取。

## 接入方式

主要是桌面客户端；免费试用额度绑定 ZCode 客户端，官方文档明确不能把试用额度路由到 Claude Code/Kilo/自己的 API 脚本。

## 限制与风险

只有 5 天；额度按天给，过期作废；不能导出到自有 Agent；免费档没有稳定 API。

## 适合谁

适合短期试 ZCode Agent；不适合作为长期免费后端。
