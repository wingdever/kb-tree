# Cursor Free

Cursor 在 2026 年 10 月并入 X Subscription 后，Free 仍是 $0 档，保留本地 Agent、Chat 与 Tab，但额度是“有限”而非公开固定数字。


## 免费额度

官方只写“有限 Agent 与 Chat 用量”，未公布固定条数；免费档只能用 Cursor 模型（Grok 与 Composer），不能用第三方模型，也不能用自带 API Key；Cloud Agents、Automations、Bugbot 等不包含。

## 接入方式

主要入口是桌面 IDE 与官方 CLI；免费档没有公开的 Agent API/SDK，接入自有 Agent 只能走本地 CLI 或 UI 自动化，稳定性一般。

## 限制与风险

限量不透明，无法做容量规划；第三方模型不可用；免费档不能自带 Key；云端 Agent 与自动化不包含。

## 适合谁

适合个人试用 Cursor 的本地 Agent；不适合作为可计量的外部 Agent 后端。
