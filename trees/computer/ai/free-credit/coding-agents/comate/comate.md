# Baidu Comate Free

文心快码（Baidu Comate）的个人标准版长期免费，注册送积分；积分用完后自动切到 Auto 免费模式，仍有每日限额。


## 免费额度

个人标准版 Free，赠送 5,000 积分；积分用尽后切 Auto 免费模式，每日有限额；个人专业版 59 元/月含 25,000 积分；旗舰版 199 元/月含 100,000 积分。

## 接入方式

主要是 IDE 插件与 Comate AI IDE，没有公开的 Agent API；接入自有 Agent 只能走 UI 自动化，属于弱接入。

## 限制与风险

5,000 积分是一次性赠送；Auto 免费模式每日限额且模型能力受限；免费档不含专业版 Auto-Free 权益；无公开 API。

## 适合谁

适合个人在 IDE 内做轻量补全与 Agent 任务；不适合外部集成。
