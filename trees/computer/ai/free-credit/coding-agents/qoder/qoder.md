# Qoder Free

Qoder（国内为 Qoder CN，原通义灵码）是阿里系的 Agentic Coding IDE；免费档是“有限体验额度”，不是长期大额度。


## 免费额度

官方计费页写：免费档含 2 周 Pro 试用与 300 Credits；社区版文章另称认证用户每月 100 Credits，基础补全与简短问答不消耗额度。两套口径并存，引用时以账号实际显示为准。

## 接入方式

Qoder CN 提供 Desktop、JetBrains 插件、Qoder CLI 与移动端，Credits 跨产品共享；CLI 可被自有 Agent 调用，但免费额度只够试用。

## 限制与风险

300 Credits/2 周只是试用；免费档补全次数有限；高阶 Agent、Quest、专家团等消耗 Credits；Qoder 全球版与 CN 版账号/额度不通用。

## 适合谁

适合试用 Qoder 的 Agent 能力；不适合长期免费使用，更不适合生产。
