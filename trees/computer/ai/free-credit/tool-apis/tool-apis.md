# 工具型免费 API

翻译、向量化、重排、OCR、语音识别属于"单一变换"类接口：不生成对话，只把一种输入转成另一种输出。它们的免费额度和对话模型完全不是一个逻辑——**计费单位不是 token，而是字符、页、次、秒、小时**，所以"免费额度有多少"必须先问单位。

## 先分清五种计费单位

| 单位 | 典型接口 | 换算陷阱 |
|---|---|---|
| 字符 | 文本翻译 | 一次请求最多几千字符，长文档要切片 |
| 次/页 | OCR、文档解析 | 按接口计次，多接口常共用一个池 |
| 秒/小时 | 语音识别 | 常只对"被判为语音"的时长计费，比音频总时长短 |
| token | 向量化、重排 | 与文本翻译的"字符"不是一回事 |
| 神经元（Neurons） | 边缘推理平台 | 平台自己的计价单位，需按模型查单次消耗 |

看额度前先确认单位，否则会出现"每月 100 万"和"每月 5 万"被当成同一量级的误判。

## 翻译

百度通用翻译 API 分三档，免费的那档限制在并发而不在字量：

| 档位 | 免费额度 | 限制 |
|---|---|---|
| 标准版 | 无需认证，官方升级说明写"不限字符量免费使用" | QPS 为 1，只够脚本与小工具 |
| 高级版 | 每月约 100 万字符（个人认证） | QPS 10，超出按 49 元/百万字符 |
| 尊享版 | 每月约 200 万字符（企业认证） | QPS 100 |

**这里有个口径冲突要记住**：老版说明与部分渠道页仍写"标准版每月 5 万字符"，而官方的服务升级说明已改为"不限字符量、QPS 1"。两者都能在官方域名下找到，接入时以开通页当时显示为准；按"5 万字符/月"做容量规划会低估，按"不限量"做生产规划会忽略 QPS 1 的排队问题。

## 向量化

Cloudflare Workers AI 是少数"每天固定送、不需要新用户资格"的入口：

- 免费额度 10,000 Neurons/天，每天 UTC 零点重置，超出即报错而不是自动扣费。
- 计价按模型换算：BGE-M3 这类嵌入模型约 1,075 Neurons/百万输入 token，折算下来每天大约 900 万 token 的免费向量化量（**推算值**，按官方每模型单价可自算）。
- 账户维度共享，所有模型吃同一个 Neuron 池；跑大模型推理会瞬间吃掉额度，向量化任务要与之分账号。

优势是"持续、可预期"；劣势是网络与账号门槛（需要 Cloudflare 账号与 Workers 能力），以及中文语义效果要自己测。

## 重排（rerank）

纯免费的托管重排接口很少，常见做法是：

- 用免费嵌入接口做召回，把 rerank 放到本地：`bge-reranker` 系列在消费级硬件上可跑，几十条候选的重排延迟可接受。
- 需要托管时，重排通常按 token 计费且单价高于嵌入，免费额度更紧；把它算进总预算时，重排往往是第二贵的环节（第一是生成）。

## OCR

腾讯云文字识别把免费额度做成"资源包"，规则值得逐条读：

- 通用文字识别、卡证、票据、文档智能等**多数接口共享 1,000 次/月**，每月 1 号自动发放，仅当月有效。
- 部分专项接口（公式识别、手写作文、文档抽取 Pro 等）是**一次性 1,000 次、一年有效**，只发一次。
- 2021 年 12 月 14 日前开通的老账号，免费包耗尽后会自动转后付费——不主动关闭就会持续出账，这是最容易被忽略的一条。

本地替代是 PaddleOCR：无额度限制，但要自己的算力与运维；扫描件、表格、发票这类版式复杂的场景，开源模型的版式还原能力差异明显，先在自己的样本上测。

## 语音识别（ASR）

阿里云的免费额度分两套，按接口选：

| 接口 | 免费额度 | 刷新方式 |
|---|---|---|
| Paraformer 实时/录音识别 | 每主账号每月 36,000 秒（10 小时） | 每月 1 日零点重置 |
| 录音文件识别（试用版） | 新用户 3 个月试用，每 24 小时可免费识别 2 小时 | 按 24 小时滚动 |

两条容易忽略的规则：计费只算"被判为语音"的时长，静音段不计；录音文件识别的免费任务排队优先级低，24 小时内完成，付费用户 3 小时内。

讯飞开放平台的语音听写按应用发放试用额度，实名后可在控制台看到具体次数；它的优势是中文与方言识别与流式接口成熟，具体数字随活动变化，接入前以控制台为准。

## 四个通用坑

1. **共享池 vs 独立池**：同一厂商的多接口常共用一个资源包，用 OCR 的额度去估另一项就错了。
2. **当月清零**：按月发放的额度不结转，月底冲刺式使用等于浪费。
3. **用尽自动转付费**：部分老产品默认开后付费，额度耗尽不是报错而是开始计费。
4. **QPS 比总量更致命**：翻译标准版字量不限但 QPS 1，批量任务会把时间成本放大几十倍。

## 一句话主线

工具型 API 的免费额度要按**单位**读、按**池**算、按**刷新周期**用：翻译看并发、嵌入看神经元、OCR 看共享次数、ASR 看小时——四项都不是"有多少 token"能回答的问题。
