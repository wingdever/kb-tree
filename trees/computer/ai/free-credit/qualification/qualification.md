# 资格型额度

按量赠送的额度解决"能不能试"，资格型额度解决"能不能撑住一个项目"。前者看调用量，后者看身份：学生、在读研究者、注册不久的创业公司、活跃开源项目、黑客松参赛者。身份门槛本身就是成本，但一旦通过，额度往往比注册赠送大一个量级，且常附带工具链、培训与曝光。

## 为什么资格比用量更值钱

- **额度规模不同**：注册赠送通常够跑通几条流程；资格型额度常以月或年为单位发放，能覆盖原型期甚至早期上线。
- **附带资源**：除算力额度，还常给开发工具、数据库、监控、域名、CI 分钟的打包权益，省下的是整张账单而不是单项。
- **审核换信任**：需要证明学生身份、公司注册信息或项目活跃度，平台因此愿意给更高额度，也更少突然收回。
- **续期规则明确**：多数计划按学期、财年或项目里程碑续期，比活动返还可预期。

代价是申请材料与合规约束：非商业用途、成果署名、数据使用范围、公司股权或营收门槛，写在小字里。

## 学生与教育包

适合在校生与教师，核心凭证是学校邮箱、在读证明或教师身份。

- **GitHub Student Developer Pack**：打包开发工具与云服务试用，按学生身份逐年复核；包含私有仓库、CI 分钟、部分云厂商额度与域名优惠。
- **JetBrains 教育许可**：学生与教师可申请全系 IDE 教育授权，用于学习与非商业项目，毕业后需转商业许可。
- **Azure for Students**：以学校邮箱验证，给一定额度的云服务信用，通常按年发放，需要绑定教育身份。
- **云厂商学生计划**：部分厂商另设学生认证，给模型调用额度或实验机时，通常限制并发与非商业用途。

使用要点：教育身份不得转让；用学校邮箱注册的服务，毕业后可能失效，项目要提前准备迁移路径。

## 创业与加速计划

面向注册时间不长、处于原型到早期增长阶段的公司，凭证是营业执照、公司域名邮箱与产品说明。

- **AWS Activate**：分层发放云资源信用，早期层门槛低、额度小，加速器或风投背书可进更高层；信用多用于抵扣云资源消费，有有效期。
- **Google for Startups Cloud Program**：按阶段给云信用与技术支持，需要公司信息与产品链接，信用通常限定在特定服务。
- **Microsoft for Startups Founders Hub**：以公司阶段审核，给 Azure 信用、开发工具与顾问资源；对营收与融资有分层要求。
- **NVIDIA Inception**：面向 AI 初创，提供 GPU 折扣、云合作伙伴额度与技术对接，不是纯现金信用，价值取决于是否需要其生态。

使用要点：信用常限定"新消费"、不可提现、不可叠加其他折扣；把额度写进现金流预测前，先确认抵扣范围与到期日。

## 科研资助

面向高校、国家实验室与非营利研究机构，凭证是机构邮箱、课题说明与数据管理计划。

- **Google Cloud 研究信用**：按课题申请，支持大规模实验与教学，通常要求成果致谢并遵守使用范围。
- **AWS 科研信用**：通过机构渠道申请，用于科研与教学负载，额度与项目周期绑定。
- **Azure 科研计划**：面向合格机构提供云与 AI 资源，申请材料侧重研究计划与合规。
- **国家与地区超算中心**：以机时而非 token 计量，申请门槛是课题评审，适合确定性的大规模训练或仿真。

使用要点：科研额度通常禁止商业转化；论文致谢、数据存放位置、成果许可要按资助条款执行。

## 开源与黑客松

面向公开仓库维护者、黑客松参赛者与社区项目，凭证是仓库活跃度、star 与贡献记录，或活动报名。

- **开源项目赞助计划**：云厂商与工具商对活跃仓库给 CI、托管、监控或模型调用额度，通常按项目而非个人发放。
- **黑客松赠金**：活动期间给参赛队 API 信用或云资源，赛后可能转为折扣；评审侧重可用性与完成度。
- **社区教育计划**：面向讲师与课程作者，给教学用额度，常要求课程公开或非商业。

使用要点：赠金多有时限与用途限制；用赠金搭的服务若转为长期运营，要重新核算单价。

## 申请顺序与材料

1. 先列目标：要的是模型调用、GPU 机时、托管还是整套工具，别为不需要的权益花时间。
2. 备一份可复用材料：身份证明、机构邮箱、公司注册信息、项目一页说明、数据管理计划。
3. 从门槛低、审核快的开始，拿到额度后立刻跑一个可验收的最小任务，确认抵扣范围。
4. 记录到期日与续期条件；把"额度到期"当成项目里程碑，而不是意外。
5. 多条额度并行时，按服务而非按厂商分配，避免同一件事重复申请。

## 边界与合规

- 资格型额度绑定身份，转售、代申、伪造在读或公司信息会被回收并限制账号。
- 非商业条款下做的产品不能直接收费；转商业前换许可或付费，别等用户付费后才处理。
- 用额度产生的数据与成果，归属、许可与致谢按计划条款执行；科研项目尤其要提前确认。
- 额度不是收入：不能计入营收，也不能作为对外承诺的容量保证。

## 一句话主线

资格型额度的本质是**用可验证的身份换更大的预算与更长的周期**：先确认自己符合哪一类，再按抵扣范围、有效期与合规约束决定用在哪一段，而不是把额度当免费产能。
