# 世界模型（World Models）

世界模型是 AI 系统建立的**内部环境表征**，用来预测环境如何随观察与行动而演化——让智能体在行动前"先想象后果"，而不必每次都在真实世界试错。它呼应心理学的心智模型：人过马路前会在脑中预演"车几秒到面前"，无需真走一次。

它与 LLM 的根本区别：**LLM 预测文本序列的下一个 token，世界模型预测物理/视觉环境的下一个状态**——捕捉重力、物体永久性、运动连续性等因果律，而非符号统计关系。

## 思想源流

- **1943**：心理学家 Kenneth Craik 提出"心智模型"——大脑构建现实的小规模模型来预测外部事件。
- **1990s**：Schmidhuber 等用 RNN 从观察预测未来状态，训练 Agent 而不靠真实试错。
- **2018**：David Ha 与 Jürgen Schmidhuber 的《World Models》——Agent 学会视频游戏的压缩模型，然后"在梦里"（自己的模拟里）训练。
- **2019**：DeepMind MuZero——学从未告知规则的游戏的模型。
- **2022**：Yann LeCun 提出 JEPA（联合嵌入预测架构），主张智能需要世界的预测模型而非纯模式匹配。
- **2025–2026**：海量视频数据 + 架构进步 + 算力使理论落地为产业；LeCun 离开 Meta 创办 AMI Labs（2026-03 融资约 10 亿美元），李飞飞创办 World Labs。

## 两种表征路线（核心分歧）

### 潜在表征派（"心算"）—— JEPA / Dreamer

在**压缩的抽象潜空间**预测未来状态，不重建每个像素。论点是：视频里大部分变化（树叶沙沙、光影闪烁）本不可预测，试图重建每像素会浪费算力在无关噪声上，且学到"平均模糊"而非抽象因果结构。

- **JEPA**（LeCun）：预测抽象表征而非像素。V-JEPA 2 在超百万小时互联网视频上训练，仅用不到 62 小时机器人轨迹微调，就在动作预测与零样本机器人规划上达 SOTA。
- **Dreamer**（Hafner）：源自模型基 RL，RSSM 把序列拆成 belief state（长期记忆）+ stochastic state（环境随机性），原生面向机器人控制。
- 优点：样本效率高、适合规划决策。缺点：黑箱、难调试（看不见模型在"想"什么）、接口复杂、泛化待验证。

### 像素/生成派（"画画"）—— Sora / Genie

显式逐帧生成未来画面，把渲染本身当作模拟器。在海量互联网视频上训练自回归 Diffusion Transformer，接受文本/图像/动作提示，生成时间一致、物理合理、照片级真实的未来帧。

- **Genie 3**（DeepMind 2025）：首个交互式通用实时世界模型，文本提示生成可导航的 3D 世界，24 fps 实时可探索。Genie 4（2026）加入声音。Project Genie 约 250 美元/月。
- **Sora**（OpenAI 2024）：定位"世界模拟器"，但常犯基础物理错误；2026-03 关停 Sora app，团队转向机器人世界模拟。
- **Cosmos**（NVIDIA 2025–2026）：开放权重的世界基础模型（WFM），为机器人/自动驾驶生成物理合理视频，支持 Text2World / Image2World / Video2World，下载超 200 万次。
- 优点：数据充足、视觉真实、变现路径短、易评估。缺点：物理正确性不足、长期状态漂移、运行贵、多为一次性生成整段视频——**真正的交互需要逐帧接收动作的骨干**。

### 空间结构派（"搭积木"）—— 3D 世界模型

显式建模场景的空间几何、体积、深度，输出带结构的 3D 表征（NeRF、3D 高斯溅射、网格），而非 2D 像素。代表：World Labs Marble（李飞飞，文本/图像/视频生成 3D 世界）、NVIDIA Omniverse、腾讯混元 3D。

- 优点：物理基础真实、可精确得到尺寸/位置/遮挡/体积、可解释可调试可接工程系统、适配机器人抓取与自动驾驶。缺点：3D 标注数据稀缺昂贵、渲染重建算力开销大、动态物理与接触建模弱。

**融合是主流方向**：像素模型负责高保真生成，空间模型负责几何一致，潜空间模型负责高层预测规划，显式物理约束负责安全边界。WorldVLA 用统一 token 化策略把图像/文本/动作纳入同一表征空间；Cosmos 3 把动作作为核心模态；NVIDIA 提出"VLA 已死，世界动作模型（WAM）是未来"。

## 四类架构（技术视角）

| 架构 | 做法 | 代表 |
|---|---|---|
| **JEPA** | 去掉生成解码器，只在潜空间预测抽象表征，忽略不可预测背景细节 | V-JEPA（Meta） |
| **RSSM**（循环随机状态模型） | belief state + stochastic state 处理序列与环境随机性 | Dreamer |
| **树搜索模型** | 预测下一隐藏状态、动作价值、即时奖励，配 MCTS 规划 | MuZero |
| **生成式基础模拟器** | 海量视频上的自回归 Diffusion Transformer，实时生成未来帧 | Genie、Cosmos |

## 功能三角（李飞飞分类）

世界模型的三种功能：**生成（renderer，输出像素）→ 理解/模拟（simulator，输出状态）→ 规划（planner，输出动作）**，最终走向统一。其中模拟/互动被视为最关键也最难——生成漂亮画面不难，难的是生成"可走进去、可互动、物理合理"的空间。

## 判断能否落地物理世界的四个能力

- **action-conditioned**：能否预测智能体动作对环境的影响。
- **uncertainty-aware**：能否表达多种可能未来（带概率的状态分布），而非单一路径——物理世界的未来不是一条轨迹。
- **temporally consistent**：长时序保持状态一致。
- **controllable**：能稳定接入规划器、控制器、安全系统。

## 衡量指标与基准

- 视频/图像质量：FVD、LPIPS、感知质量。
- 物理一致性、动作条件一致性、长时序漂移。
- 规划价值：在模拟中训练的策略迁移到真实世界的成功率。
- **FLORES-200**（NLLB）、WMT 类基准的思路可借鉴；具身领域用 simulation-to-real 转移评估。
- 注意：多数安全基准本身是机器翻译/生成出来的，存在循环评估问题。

## 主要挑战

- **数据稀缺**：LLM 抓取的是基本免费的互联网文本；世界模型需要**第一人称、带动作标注**的数据（视频 + 产生它的控制/力），稀缺且昂贵。拥有数据尾气（YouTube、车队）或独有数据源的公司占优。
- **一致性与记忆**：生成的世界会漂移变形，长期保真难。
- **物理正确性**：视频真实感 ≠ 物理准确；物体交互、接触、长期状态漂移仍普遍存在。
- **可解释性**：潜空间路线难调试，输出与内部状态不一致时不易检测。
- **交互真实性**：判别"交互式 demo 是真逐帧响应还是预录"——看骨干是否逐帧接收动作。
- **对齐风险**：能预见行动后果的系统能更有效地追求目标——"for better or worse"。

## 与 LLM 的关系

世界模型**不是取代 LLM 做对话/写作**，它解决不同问题：空间推理、物理模拟、动作规划——所以先在自动驾驶、机器人、游戏落地。LLM 路线（文字接龙）天花板渐显，一批研究者转向让 AI 直接理解世界本身。两条路线长期可能融合（VLA、WAM）。

关于"LLM 是否已自发形成世界模型"：2022 年研究发现小模型在 Othello 棋谱上训练后形成了从未示意的棋盘内部地图；也有人在 LLM 中发现空间/时间表征。怀疑者（LeCun 等）反驳说这些只是世界的"统计影子"——2024 年研究发现擅长城市导航的模型持有的地图在小改动下就会崩塌。这个答案关系到当前方法能走多远。
