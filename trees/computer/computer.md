# 计算机（Computer Science）

计算机科学是研究**计算、信息与自动系统**的学科——既关注抽象的计算本质（算法、复杂度、可计算性），也关注其物理实现（硬件、体系结构）与工程落地（软件、系统、应用）。

本文件是"计算机"这个知识节点的内容介绍，讲这个学科研究什么、有哪些主要分支。

## 研究范畴

计算机科学的核心问题可以概括为三层：

- **理论层**：什么可计算、如何高效计算——算法与数据结构、计算复杂度、可计算性理论、信息论、形式语言与自动机。
- **系统层**：如何构建可靠高效的计算系统——计算机组成原理（硬件）、操作系统、计算机网络、数据库系统、体系结构。
- **应用层**：如何用计算解决问题——软件工程、人工智能、图形学、人机交互、分布式系统等。

## 与其它学科的关系

计算机科学与数学（逻辑、概率、线性代数）、认知科学（心智、语言）、电子工程（硬件实现）深度交叉。人工智能尤其与认知科学、语言学、神经科学交融；计算机组成原理建立在电子工程之上；软件工程则与系统工程、人机交互相接。
