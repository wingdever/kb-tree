# ima

ima 是腾讯的 **AI 知识库工具**（2024-11 上线），核心是「收藏 + AI 理解 + 智能问答」；2026-04/05 上线 copilot，从一次 RAG 回答升级为围绕任务持续查找、判断与交付的 Agent。本页记平台层差异。

## 形态与厂商

- 厂商：腾讯；入口 `ima.qq.com`，有 Web、PC 客户端、手机端。
- 定位：面向个人的知识库 + Agent 协作平台；知识号让创作者发布 Skill，形成内容分发。

## Agent 化后的能力

| 能力 | 表现 |
|---|---|
| 按任务选查找方式 | 自动匹配语义检索或关键词查找——错误码这类不可改写的值走精确关键词 |
| 先定位文件再读内容 | 只记得文件名或按上传时间盘点时，先查文档列表与时间信息再读正文 |
| 限定范围 | 可指定文件、文件夹、标签、时间范围；未确认不擅自扩大到全库 |
| 分步骤补证据 | 跨文档比较、多指标核对时先拆解问题，针对缺口继续查找，资料足够才停 |
| 来源区分 | 只有用户明确提出「联网查询 / 结合公开信息」才用网络搜索，并区分内部资料与公开信息 |
| 成果交付 | 把查找、比较、归纳结果生成报告或表格供下载流转 |

## 记忆与技能

- **四层记忆**：Copilot 设定（风格）、用户档案（身份与偏好）、长期记忆（项目与决策）、经验技巧（使用中积累）。记忆在设置卡片可见，可通过对话编辑——不是黑盒。
- **知识库直连**：直接读取 ima 内文件、笔记与资料，跨文档汇总整理与生成。
- **Skill 体系**：内置官方 Skill，支持安装与自定义分享；知识号可发布 Skill（微信读书助手、腾讯招聘助手等首批）。
- **模型矩阵**：接入 GLM 系列、腾讯混元、DeepSeek V4-Flash 等，也支持自定义 API Key 接入更多模型。

## 安全与边界

- 明确区分「知识库内资料」与「公开网络信息」，联网需显式授权——这是来源边界的显式设计。
- 限定范围查询默认不外扩，避免跨知识库泄露。
- Skill 来自第三方创作者，安装前按依赖审查，与 MCP server 的审查逻辑同类。
