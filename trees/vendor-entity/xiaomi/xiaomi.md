# 小米集团

小米属于"境外上市 + 硬件制造在境内 + 互联网服务另设主体"的类型。它的 C 端 Agent 不是独立 App，而是长在手机与 IoT 系统里的语音助手，这决定了责任主体与签约主体都不一样。

## 主体结构

| 项 | 内容 |
|---|---|
| 注册地 | 开曼群岛，以不同投票权架构上市 |
| 上市 | 2018 年 7 月在港交所主板挂牌，代码 1810 |
| 境内制造与销售 | 由境内通讯与移动通信类公司承担，涉及生产、渠道与售后 |
| 境内互联网服务 | 由移动软件类公司承担，涉及应用商店、云服务、账号体系 |
| 生态链 | 大量参股而非控股的生态链公司，品牌授权与股权关系要分开看 |

## 产品与主体

- **手机与 IoT 硬件**：销售主体、生产主体、售后主体可能不是同一家公司，保修按销售合同走。
- **系统级助手**：超级小爱属于端侧助手，账号、语音数据与模型推理的处理者由系统服务协议约定。
- **云与模型**：自研模型的训练与端侧部署涉及云资源与终端两套体系。
- **生态链产品**：贴着小米品牌销售但由生态链公司制造，质量责任与数据责任要按具体产品协议确认。

## 对合作方的含义

- 采购硬件看销售合同主体，做软件合作看互联网服务主体，两者的合规要求不同。
- 端侧助手的数据处理涉及语音、联系人等敏感权限，合作前要确认权限与留存策略。
- 生态链公司的品牌授权不等于集团担保，出问题时的责任主体是制造方。

## 怎么核实

1. 用港股公告与年报确认上市主体与主要子公司范围。
2. 硬件合同核对签约方与生产方是否一致，售后条款写明承接主体。
3. 软件与 AI 合作核对账号体系归属与数据处理者。
4. 生态链产品查产品页的生产企业与授权关系。

## 常见误区

- **以为小米所有产品都由集团一家公司生产**：生态链模式决定了制造方分散。
- **把品牌授权当成质量担保**：责任按产品协议与生产企业确定。
- **忽略端侧数据的两层处理**：终端权限与云端推理分属不同环节。
- **以为港股 1810 就是境内签约主体**：注册地在开曼，日常合同在境内公司。

## 一句话主线

小米的资本在开曼、制造在境内、服务在另一批境内公司：**买硬件看销售主体，用助手看数据处理者，买生态链产品看生产企业**。
