# 北京金山办公软件股份有限公司

金山办公是"境内科创板上市 + 订阅制 C 端产品 + 政企信创市场"的组合。它的 AI 能力长在办公套件里，而不是独立聊天入口，判断它是否属于 C 端 Agent 要看产品形态而不是宣传词。

## 主体结构

| 项 | 内容 |
|---|---|
| 上市主体 | 北京金山办公软件股份有限公司，上交所科创板，代码 688111 |
| 上市时间 | 2019 年 11 月 18 日 |
| 注册地 | 北京市海淀区，境内注册、境内上市 |
| 股权关联 | 与港股金山软件、港股与纳斯达克两地上市的金山云同属金山系，各自独立上市 |
| 业务模式 | 个人订阅 + 机构授权 + 信创适配 |

## 产品与主体

- **WPS Office**：个人版与专业版，订阅收入来自个人用户与机构客户。
- **WPS AI**：文档写作、表格分析、演示生成等能力嵌入套件内，属于办公场景智能体。
- **灵犀**：面向办公的对话式入口，与套件深度集成。
- **政企与信创**：机构合同涉及部署方式（公有云、私有化、混合），数据驻留要求不同。

## 对合作方的含义

- 个人订阅与机构采购是两套合同体系，发票与授权方式不同。
- 私有化部署时，文档数据留在客户侧，处理者角色与公有云模式相反。
- AI 功能涉及文档内容上传，合同里要明确是否用于模型训练。
- 与金山系其他公司的合作不能互相替代，签约主体各自独立。

## 怎么核实

1. 用科创板公告与年报核对主体与子公司范围。
2. 机构合同看清部署模式与数据处理条款，尤其是训练数据授权。
3. 个人订阅条款确认自动续费与退款规则。
4. 涉及信创适配时核查资质与兼容清单。

## 常见误区

- **以为 WPS AI 是独立产品公司**：它属于办公套件主体的一项能力。
- **把金山办公与金山软件当成一家**：两地、两个上市主体。
- **忽略部署模式对数据责任的影响**：私有化与公有云的处理者不同。
- **以为订阅用户数据一定不上传**：AI 功能可能触发内容上传。

## 一句话主线

金山办公是境内上市的办公软件公司：**个人看订阅条款，机构看部署模式，AI 功能看数据授权**。
