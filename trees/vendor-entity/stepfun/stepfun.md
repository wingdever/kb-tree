# 阶跃星辰

阶跃星辰走的是"模型往终端里装"的路：不靠自有流量做入口，而是把模型卖给手机、汽车与 IoT 厂商。这决定了它的资本叙事与消费级 Agent 公司不同——客户是厂商，不是用户。

## 主体结构

| 项 | 内容 |
|---|---|
| 主体 | 上海阶跃星辰智能科技有限公司，注册在上海 |
| 资本状态 | 未上市，多轮私募融资，投资方含终端产业链资本 |
| 治理 | 由董事长与创始团队主导，产业投资方进入董事会层面观察 |
| 战略 | 端侧、车载、多模态，与硬件产业链深度绑定 |

## 产品与主体

- **跃问**：面向消费者的多模态问答与智能体入口。
- **端侧模型**：面向手机与终端厂商的轻量化模型交付。
- **车载方案**：与整车厂合作，模型进入座舱，责任边界按车规要求划分。
- **开放平台**：API 与企业调用，条款独立于 C 端产品。

## 对合作方的含义

- 客户结构以厂商为主，个人用户体验由终端品牌承担，模型方责任有限。
- 车载合作涉及功能安全与召回责任，合同要把责任切分写清。
- 未上市，财务与估值信息稀缺，长期供货能力要靠交付记录判断。
- 端侧部署涉及模型压缩与授权范围，权重使用要单独约定。

## 怎么核实

1. 工商核对主体与股东，确认产业投资方的进入方式。
2. 终端合作看整机厂的发布与适配清单，而不是模型方的宣传。
3. 车载项目核查车规资质与责任条款。
4. 端侧授权确认可部署设备数量与更新机制。

## 常见误区

- **以为它有大量 C 端用户**：流量主要在合作终端里，不在自有 App。
- **把融资额当成营收**：融资是一次性现金，营收是持续交付。
- **忽略车载责任链**：模型方、Tier1、整车厂三方责任不同。
- **以为端侧模型可以随意分发**：授权通常限定设备与场景。

## 一句话主线

阶跃星辰是"模型供应商"而不是"流量入口"：**C 端看跃问，收入看终端客户，风险看车载与授权条款**。
