# 昆仑万维科技股份有限公司

昆仑万维属于"境内上市 + 全球化业务 + 子公司另有上市平台"的类型。主体本身不复杂，复杂的是它把一部分资产放在境外上市公司里，读财报时容易把合并口径和签约口径混起来。

## 主体结构

| 项 | 内容 |
|---|---|
| 上市主体 | 昆仑万维科技股份有限公司，深交所创业板，代码 300418 |
| 注册与经营 | 境内注册、境内上市，不存在开曼控股层 |
| 海外平台 | 控股 Opera 等境外上市公司，音频社交等资产以子公司形式存在 |
| 战略定位 | All in AGI 与 AIGC，形成"算力—模型—应用"三层 |

## 业务与产品

- **天工系列**：天工大模型与天工 AI 应用，面向消费者的智能体入口。
- **视频生成**：SkyReels 系列视频模型，面向短剧与内容创作场景。
- **海外互联网**：浏览器、音频社交等业务通过境外子公司运营，收入以海外为主。
- **投资与并表**：对外投资标的可能并表也可能不并表，读财报要看合并范围注释。

## 对合作方的含义

- A 股上市公司有公开财报与公告，供应商准入的证据链比未上市公司完整。
- 海外子公司是独立法人，境内合同不能约束境外主体，反之亦然。
- 模型服务与视频生成服务的合同主体，要看具体产品对应的境内公司。
- 涉及内容生成时，版权与深度合成标识责任要在合同里写清。

## 怎么核实

1. 用深交所公告与定期报告确认合并范围，区分并表子公司与参股公司。
2. 海外平台单独查其上市地披露，不要用母公司公告替代。
3. 合同抬头核对是否为境内上市主体或其并表子公司。
4. 内容类合作核查版权来源与生成内容标识义务。

## 常见误区

- **把 Opera 当成昆仑万维本身**：它是有独立上市平台的子公司。
- **以为海外收入等于海外主体签约**：收入确认与合同主体是两件事。
- **用市值判断履约能力**：股价波动大，现金流与合同负债更可靠。
- **忽略内容合规**：视频与文本生成涉及标识、版权与审核责任。

## 一句话主线

昆仑万维是境内上市的全球化公司：**母公司看 A 股公告，海外资产看子公司披露，合同按法人签**。
