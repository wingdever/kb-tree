# 月之暗面（Moonshot AI）

月之暗面是"未上市、但已经改成股份公司"的典型：工商形态像上市公司，资本状态却仍是私募市场。它的对外形象集中在 Kimi 一个产品，这让它成为理解"品牌极简、主体极重"的好样本。

## 主体结构

| 项 | 内容 |
|---|---|
| 主体 | 北京月之暗面科技股份有限公司（由有限公司改制而来） |
| 成立 | 2023 年 4 月，注册在北京海淀 |
| 创始人 | 杨植麟，法定代表人，研究背景出身 |
| 资本状态 | 已完成多轮融资，最新轮次为 F 轮级别；未在任何交易所上市 |
| 上市传闻 | 据报道已保密递交港股申请、目标 2027 年一季度，属媒体口径，未获公司确认 |

## 产品与主体

- **Kimi**：面向消费者的长文本与智能体产品，是主要流量入口。
- **开放平台**：面向开发者的模型调用，计费与条款独立于 C 端订阅。
- **企业方案**：私有化与混合部署，数据驻留要求与公有云不同。
- **多模态与工具调用**：产品能力持续扩展，条款随版本更新。

## 对合作方的含义

- 未上市公司没有公开财报，信用评估只能靠工商、诉讼、融资交割与客户案例。
- 股份公司形态便于后续上市，但不代表已经具备公众公司披露义务。
- 消费级产品条款变动频繁，长期合作要把服务水平与数据条款写进合同。
- 上市传闻不构成事实，写进尽调报告要标注来源与不确定状态。

## 怎么核实

1. 用工商登记核对主体名称、成立时间、注册资本与股东。
2. 融资与估值以公司公告或投资方披露为准，媒体数字只作参考。
3. 合同抬头确认是否为股份公司本体，避免用到未登记的关联方。
4. 关注产品条款版本，尤其是数据使用与模型训练授权。

## 常见误区

- **把股份公司当成已上市公司**：改制只是组织形式变化。
- **用估值传闻做信用判断**：估值不是偿付能力。
- **以为 Kimi 只有一个签约主体**：C 端、开放平台、企业方案条款分开。
- **忽略条款更新**：消费级产品的隐私与数据条款可能随版本调整。

## 一句话主线

月之暗面是"产品极简、主体在改制、资本在私募"的公司：**看主体看工商，看估值看交割，看合同看产品线**。
