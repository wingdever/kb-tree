# 维沃移动通信有限公司

vivo 和 OPPO 同属"东莞系"终端厂商，结构相似但细节不同：注册资本规模小、主体名称与品牌名完全脱钩，这是核对合同时最容易出错的地方。

## 主体结构

| 项 | 内容 |
|---|---|
| 主体 | 维沃移动通信有限公司，前身为艾酷电子科技有限公司 |
| 注册与经营 | 广东省东莞市长安镇，境内注册 |
| 资本状态 | 未上市，无公开财报 |
| 品牌关系 | "vivo"是品牌，法人名里没有 vivo 字样 |
| 业务 | 智能终端、影像技术、系统服务、海外销售 |

## 产品与主体

- **蓝心小 V**：系统级助手，随 OriginOS 预装。
- **蓝心大模型**：端云协同的模型体系，覆盖语言、图像与语音。
- **应用商店与云服务**：由境内互联网服务主体运营，账号体系统一。
- **海外市场**：按国家分区运营，合规主体随销售地变化。

## 对合作方的含义

- 合同抬头必须写"维沃移动通信有限公司"，写 vivo 无法成立。
- 预装与系统级权限涉及敏感数据，需明确授权范围与撤回机制。
- 未上市意味着没有财报可查，评估依赖工商、诉讼与行业数据。
- 海外版本与境内版本的隐私条款不同，不能互相引用。

## 怎么核实

1. 工商核对主体全称与统一社会信用代码，与品牌名做映射。
2. 系统级合作核查权限清单与数据处理说明。
3. 海外项目确认当地运营主体与认证。
4. 供应链合作核对签约方与生产方是否一致。

## 常见误区

- **在合同里写品牌名**：法人名称与品牌完全不同。
- **以为注册资本小等于规模小**：注册资本与经营规模无必然关系。
- **忽略系统助手的预装条款**：预装涉及分成、权限与默认设置。
- **用境内条款约束海外版本**：适用法律与主体都不同。

## 一句话主线

vivo 是"品牌与法人名脱钩"的典型：**签合同写维沃，查资本看股权，做系统合作看权限**。
