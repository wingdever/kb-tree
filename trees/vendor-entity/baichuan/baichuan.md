# 百川智能

百川智能是"通用模型起家、后来转向垂直行业"的案例。资本上仍是一家未上市的北京公司，业务上却把重心压到医疗，这让它的合同对象从"模型供应商"逐渐变成"行业方案商"。

## 主体结构

| 项 | 内容 |
|---|---|
| 主体 | 百川智能科技有限公司，注册在北京海淀 |
| 成立 | 2023 年 3 月 |
| 创始人 | 王小川，法定代表人 |
| 资本状态 | 未上市，融资进行至 A+ 轮级别 |
| 战略转向 | 从通用大模型转向医疗 AI，资源向垂直场景集中 |

## 产品与主体

- **百小应**：面向消费者的助手产品，是它最接近 C 端 Agent 的形态。
- **医疗方案**：面向医院与基层医疗的产品，涉及资质与数据合规。
- **模型服务**：对外 API 与企业部署，逐步与行业方案打包。
- **开源模型**：部分早期模型对外开源，商用看许可证。

## 对合作方的含义

- 战略转向意味着产品线可能收缩，长期合作要关注版本与退出条款。
- 医疗场景受强监管，合同需明确资质归属与责任边界。
- 未上市，财务信息有限，交付能力靠案例与团队规模判断。
- 消费级产品与企业方案的数据条款分开，不能互相套用。

## 怎么核实

1. 工商核对主体、股东与法定代表人。
2. 医疗合作核查资质、数据合规与临床验证材料。
3. 关注产品线变动公告，评估停服与迁移风险。
4. 开源模型查许可证，确认商用范围。

## 常见误区

- **以为它仍是纯通用模型公司**：重心已转向医疗。
- **把百小应当成全部业务**：企业方案占比在上升。
- **忽略战略调整的合同风险**：产品停服与迁移要提前约定。
- **用融资轮次判断稳定性**：轮次高不代表现金流健康。

## 一句话主线

百川智能是"未上市 + 战略转向"的公司：**看产品线是否还在，看医疗资质是否齐全，看合同里的退出条款**。
