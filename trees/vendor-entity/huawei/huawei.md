# 华为投资控股有限公司

华为是"有资本实体、但没有股票、也没有外部股东"的一类：顶层公司由工会（代表持股员工）与创始人两名股东持有，不上市、不融资、不披露季度财报。判断它时，股权结构和治理安排比财务数字更关键。

## 主体结构

| 层 | 主体 | 要点 |
|---|---|---|
| 顶层控股 | 华为投资控股有限公司 | 1987 年成立于深圳，全部由员工持有，无外部机构股东 |
| 股东 | 工会委员会 + 任正非 | 工会代表持股员工行使股东权利；任正非为自然人股东 |
| 上市状态 | 无 | 不在任何交易所上市，无股票代码、无公开股价 |
| 业务主体 | 华为技术有限公司及下属各业务公司 | 按业务线设立，签约与开票落到具体公司 |

## 股权与治理

- **员工持股**：持股员工通过工会持有公司股份，工会履行股东职责的机构是持股员工代表会，代表由持股员工一股一票选举产生。
- **创始人比例**：任正非作为自然人股东并参与员工持股，其出资占公司总股本的比例不足百分之一，且逐年小幅下降；具体数字随年度更新，以公司治理页面为准。
- **治理安排**：持股员工代表会选举董事会与监事会；经营管理由轮值董事长制度承担，创始人不是大股东意义上的控制人。
- **不对外融资**：没有外部投资人，因此没有"估值—融资轮次—优先股"这套结构。

## 模型与训练栈

华为的模型是"从芯片到权重"全栈自研，这一点决定了它在供应商评估里的位置与纯模型公司不同。

- **云侧基础模型**：盘古 5.5 覆盖五大方向，语言模型做到 718B 级混合专家结构，视觉模型为 300 亿级，另有预测、科学计算与世界模型。
- **开源线**：openPangu-2.0 分档开放，Flash 档 920 亿参数、Pro 档 5050 亿参数，训练、微调与后训练代码也逐步公开。
- **端侧模型**：鸿蒙新版本支持端侧 30B 盘古轻量化版本，配合自研轻量推理引擎按 NPU、DSP、CPU 顺序调度。
- **算力与框架**：模型在昇腾集群上训练与推理，训推一体优化，模型能力与硬件生态同源。
- **智能体框架**：系统级智能体框架向 2.0 演进，端云模型融合，应用向 Agent 与 Skill 形态改造。

对合作的含义：全栈自研意味着供给自主性高、迭代节奏由自己掌握；同时模型与昇腾绑定，迁移成本高于通用 GPU 方案。开源权重与云侧 API 是两条不同的商用路径，条款要分开看。

## 业务主体

- **ICT 基础设施与终端**：由华为技术有限公司及其下属公司承担研发、制造与销售。
- **云服务**：华为云由集团内云计算公司运营，境内有注册在贵州的云计算技术有限公司与深圳的云计算技术有限公司，两者是不同法人，签约主体要看合同。
- **数字能源、智能汽车解决方案**：各自有独立业务公司，与终端、云不是同一签约方。
- **政企与运营商采购**：常通过区域分公司或授权伙伴签约，最终责任主体仍是总部公司。

## 对合作方的含义

- **合同**：签约方是具体业务公司或授权伙伴，品牌"华为"不能作为合同主体。
- **发票**：抬头与签约主体一致；通过渠道采购时，发票由渠道方开，售后责任按合同约定。
- **数据责任**：云服务与终端服务的个人信息处理者分别对应各自运营公司，隐私政策会写明。
- **信用评估**：没有公开财报，供应商准入要依赖工商登记、诉讼记录、担保与履约历史，不能用"世界五百强排名"替代。

## 怎么核实

1. 在工商系统查签约公司的股东链，确认是否上溯至华为投资控股。
2. 核对签约主体与交付主体是否一致，渠道销售要看清授权层级。
3. 云与模型类服务单独确认运营公司，不同地域注册的公司不能互相替代。
4. 涉及员工持股安排的传闻，一律以公司治理页面与官方声明为准。

## 常见误区

- **以为华为上市或有股票代码**：从未在任何交易所上市，市面上的"华为股票"均为骗局。
- **以为任正非控股**：其持股比例不足百分之一，控制权来自治理制度而非股权。
- **把华为云与华为终端当成一家签约**：不同业务公司，合同各自独立。
- **用营收排名判断履约能力**：营收规模与现金流、偿付能力不是一回事。

## 一句话主线

华为的资本实体是员工持有的非上市公司：**没有股票可买，也没有外部股东可查，核实的抓手是股权链、治理安排和合同主体这三样**。
