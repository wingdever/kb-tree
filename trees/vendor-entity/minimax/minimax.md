# MiniMax（稀宇科技）

MiniMax 是 2026 年这波 AI 上市潮里速度最快的一家：成立四年即挂牌，采用不同投票权架构，境内运营落在上海的公司。它的产品线同时覆盖 C 端智能体与开放平台，签约主体要按产品分。

## 主体结构

| 项 | 内容 |
|---|---|
| 上市主体 | MiniMax Group Inc.，港交所主板，代码 00100，简称 MINIMAX-W |
| 上市时间 | 2026 年 1 月 9 日，发行价 165 港元，募资约 55.4 亿港元 |
| 架构特征 | 不同投票权（WVR）公司，创始人投票权高于经济权益 |
| 境内运营 | 上海稀宇极智科技有限公司等境内主体承担产品与交付 |
| 回 A 进展 | 2026 年 5 月与券商签署辅导协议，启动科创板上市辅导 |

## 产品与主体

- **C 端智能体**：MiniMax Agent 与海螺 AI，覆盖对话、创作、视频生成。
- **开放平台**：文本、语音、视频模型的 API 服务，按调用计费。
- **海外产品**：面向海外市场的应用由境外主体运营，合规体系与境内不同。
- **多模态**：语音与视频能力是它与纯文本厂商的差异点。

## 对合作方的含义

- 消费级订阅与企业 API 是两套条款，数据处理与计费方式不同。
- 视频与语音生成涉及深度合成标识义务，合同要写清责任分配。
- WVR 结构下少数股东对重大决议影响力有限，长期合作关注治理条款。
- 回 A 尚在辅导阶段，不构成已上市事实，对外表述要谨慎。

## 怎么核实

1. 用港交所公告与月报表核对代码、股份类别与股本变动。
2. 回 A 进展以辅导备案与官方公告为准，不用传闻。
3. 合同抬头确认是境内运营公司还是境外主体，跨境服务另看条款。
4. 生成式内容合作核查标识与水印要求。

## 常见误区

- **把 MINIMAX-W 的 W 当成"第二上市"标记**：它表示不同投票权。
- **以为辅导就是上市**：辅导备案距离发行还有多个环节。
- **用境外主体签境内交付合同**：履约与追责都会变复杂。
- **忽略生成内容的标识义务**：视频与语音合成有明确的合规要求。

## 一句话主线

MiniMax 是"港股 WVR 主体 + 上海运营公司 + 多模态产品"的组合：**资本看 00100，交付看境内公司，内容合规看标识义务**。
