# 零一万物

零一万物是"明星创始人 + 快速独角兽 + 战略收缩"的样本。它早期以通用模型和 C 端应用进入公众视野，后来把重心移到企业级平台，这条转身轨迹对判断合同对象很关键。

## 主体结构

| 项 | 内容 |
|---|---|
| 主体 | 北京注册的有限责任公司，境内运营 |
| 成立 | 2023 年 5 月，由李开复博士领衔创立 |
| 资本状态 | 未上市，成立半年即进入独角兽序列，后续多轮融资 |
| 战略 | 从通用模型转向企业 AI 与行业智能体，强调"一号位工程" |
| 海外延伸 | 与中亚等地合作设立合资主体，承接主权 AI 项目 |

## 产品与主体

- **万智平台**：企业大模型一站式平台，涵盖部署、微调与应用实践。
- **万策平台**：企业 AI 决策中枢，衍生出面向老板、投资、销售的智能体应用。
- **早期 C 端产品**：曾以对话助手形态面向个人，现投入已收缩。
- **行业交付**：制造、金融等场景的智能体落地，多为项目制。

## 对合作方的含义

- 业务重心在企业侧，合同以项目与平台订阅为主，个人订阅占比低。
- 转型期的产品线变动较大，长期合作要约定版本与迁移方案。
- 未上市，财务信息有限，交付能力看客户案例与团队配置。
- 合资与海外主体独立签约，境内合同不自动覆盖境外项目。

## 怎么核实

1. 工商核对境内主体与股东，确认与对外宣传的对应关系。
2. 平台类合同看清部署方式、模型来源与数据归属。
3. 项目制合同写明验收标准与知识产权归属。
4. 海外合资项目单独核查对方主体与当地合规要求。

## 常见误区

- **以为它仍是 C 端助手公司**：重心已转向企业平台。
- **把"独角兽"当信用等级**：称号不代表现金流。
- **用创始人声誉替代主体核查**：合同方是公司，不是个人。
- **忽略转型带来的停服风险**：老产品可能停止迭代。

## 一句话主线

零一万物是"创始人光环 + 企业级转身"的公司：**看它现在卖什么，看合同里的迁移条款，看主体而不是看名气**。
