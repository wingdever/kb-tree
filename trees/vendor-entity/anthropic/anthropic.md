# Anthropic（Anthropic, PBC）

Anthropic 是一家注册在特拉华州的公益公司（Public Benefit Corporation），2021 年由 Dario Amodei、Daniela Amodei 等前 OpenAI 研究人员创立，总部在旧金山。它长期是未上市的私营公司，2026 年 11 月 19 日以代码 ANT 在纳斯达克挂牌，成为首家以公益公司身份上市的前沿模型开发商。

## 主体与治理

| 项 | 内容 |
|---|---|
| 法律形态 | 特拉华州公益公司（PBC），董事须兼顾股东利益与公司章程声明的公共使命 |
| 上市状态 | 2026 年 11 月 19 日纳斯达克挂牌，代码 ANT |
| 股权结构 | A 类普通股公开交易，但投票权合计受限；另有战略伙伴持有的无投票权类别，以及由长期利益信托选任多数董事的安排 |
| 中国境内法人 | 无 |

公益公司不是"非营利"，它可以正常融资、分红与上市；差别在于董事不能只对股东负责，还要对公司章程里写明的使命负责。这套结构让它在资本市场上融资的同时，保留了一层"使命优先"的治理约束。

## 上市这件事

- **发行与首日**：发行价 83 美元/股，首日开盘 111.50 美元，收盘 97.17 美元，较发行价上涨约 17%。
- **募资规模**：初始募资约 813 亿美元，承销商行使超额配售权后升至约 935 亿美元，为当时美股规模最大的 IPO。
- **估值波动**：首日盘中市值一度突破 2 万亿美元，收盘回落至约 1.27 万亿美元（按行情平台总股本口径）。
- **上市后的含义**：有了公开财报、季报与重大事项披露，外部可以用披露文件交叉验证业务与风险，而不是只靠媒体报道。

> 判断：上市把"AI 实验室"变成了"受证券监管的公众公司"，采购与投资判断应转向 10-Q/10-K 与招股书，而不是发布会口径。

## 签约与可用性

- **服务主体**：Claude 的订阅与 API 由 Anthropic, PBC 及其关联实体提供，条款里写明的签约方是境外法人。
- **中国大陆**：不向中国大陆提供 Claude 服务，官网与 API 在大陆网络环境不可用；也无境内注册公司与 ICP 备案。
- **数据位置**：账号与对话数据由美国实体处理；企业版的数据驻留选项以合同与信任中心文档为准。
- **云依赖**：模型推理大量依托第三方云（如 AWS、Google Cloud），这层关系影响区域可用性与延迟，但不改变合同相对方。
- **转售与代理**：市面上存在第三方代理与二次封装，合同相对方是代理方，不是 Anthropic。

## 产品与主体的对应

- **Claude 个人订阅（Pro / Max）**：由 Anthropic 直接提供，账单在 Anthropic 侧。
- **Claude API 与企业版**：走商业条款，按客户所在地确定签约实体。
- **Claude Code 等开发者工具**：同属 Anthropic 产品线，计费与条款随账号类型。
- **模型权重与开放成果**：以许可方式发布的部分不构成服务合同。
- **云市场里的 Claude**：通过云厂商购买的，合同与计费在云厂商，支持也由云厂商一线承接。

## 对合作方的含义

- **无境内相对方**：需要境内发票或境内数据合规承诺的项目，官方路径不成立。
- **合同相对方**：直签是 Anthropic, PBC 的境外实体；代理转售则看代理合同。
- **数据合规**：个人信息出境评估是使用前提，网络可达不等于合规可用。
- **可用性风险**：大陆不可用是长期状态，业务连续性方案需预设替代模型。
- **投资与采购分离**：作为上市公司，投资判断看披露文件；作为服务商，采购判断看合同与 SLA，两者不要混。

## 怎么核实

1. 看服务条款里的签约实体与管辖法律条款，确认相对方全称。
2. 用纳斯达克与 SEC 披露文件核对上市状态、股本结构与财务数据。
3. 查公司章程与长期利益信托的公开说明，理解"使命控制"的实际权力边界。
4. 企业采购要求供应商说明是直签、云市场购买还是代理转售。

## 常见误区

- **把公益公司当成非营利**：它可以上市、分红，只是董事义务多一层使命约束。
- **以为上市就等于普通股份公司**：投票权与董事选任安排和常规公司不同，控制权不完全按持股比例分配。
- **把首日市值当成长期估值**：新股首日波动大，后续跌破发行价是常态。
- **以为"公益"意味着不追求收入**：它照常商业化，使命约束体现在治理而非定价。
- **拿媒体报道代替披露文件**：上市后应以招股书、季报与年报为准。

## 一句话主线

Anthropic 是"公益公司 + 双层股权 + 使命信托"的组合，2026 年 11 月以 ANT 上市：**谈服务看境外签约实体，谈治理看 PBC 与信托安排，谈投资看 SEC 披露**——三者不能互相替代。
