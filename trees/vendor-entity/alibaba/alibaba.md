# 阿里巴巴集团控股有限公司

阿里是"两地双重主要上市"的代表：同一批股份既能以美股存托股在纽约交易，也能以普通股在香港交易，两者可互换。对合作方来说，复杂点不在资本市场，而在境内几十家运营公司按业务线切分。

## 主体结构

| 项 | 内容 |
|---|---|
| 注册地 | 开曼群岛，有限责任公司 |
| 美股 | 2014 年 9 月在纽约证券交易所上市，代码 BABA，一份存托股代表八股普通股 |
| 港股 | 2019 年 11 月以普通股在港交所第二上市，2024 年 8 月转为双重主要上市，代码 9988（港币柜台）、89988（人民币柜台） |
| 治理特征 | 合伙人制度下的董事提名权被港交所视为不同投票权架构 |
| 境内运营 | 由多家境内公司分业务承担，签约与开票随业务线变化 |

## 境内主体的切分

- **电商**：淘宝、天猫等平台的运营与商业化由境内电商相关公司承担，商家协议、广告合同各找对应主体。
- **云与模型**：阿里云与企业级模型服务合同签在云计算业务主体；通义系列模型的对外服务与内部研发不是同一层。
- **本地生活与物流**：外卖、到店、配送分属不同业务公司与合资体系，主体边界比品牌边界细。
- **C 端 Agent**：千问 App、夸克等消费级 AI 产品的运营主体，与电商、云不是同一家公司。

## 对合作方的含义

- 广告投放、云资源、模型 API 三类采购，抬头往往分属三家公司，不能合并成"阿里"一个主体。
- 数据责任按产品落：电商交易数据、云上客户数据、消费级 AI 对话数据，处理者各不相同。
- 港股与美股股东权利同一，但跨境投资者适用的披露与投票规则不同，做股东沟通时要区分。

## 怎么核实

1. 从产品协议首页确认运营公司全称，再与工商登记比对股东链。
2. 云与模型类合同，核对签约主体是否具备对应业务资质与机房资源。
3. 用港交所公告与年报验证合并范围，不要用集团品牌反推合同主体。
4. 涉及跨境数据时，单独确认数据处理者与出境路径。

## 常见误区

- **以为 9988 与 BABA 是两家公司**：同一主体、两种股份形式，可互相转换。
- **把"阿里云"当成集团总部签约**：云服务有独立业务主体与合同体系。
- **以为双重主要上市等于二次发行**：转主要上市不涉及新股融资。
- **用品牌归属判断数据责任**：处理者看具体产品的隐私政策。

## 一句话主线

阿里的资本关系放在开曼与两个交易所，经营关系放在境内一串业务公司：**买什么就找那条业务线对应的法人，别拿集团名当合同主体**。
