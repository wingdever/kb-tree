# 微软公司（Microsoft Corporation）

"微软"在合同上不是一个主体，而是三层：在纳斯达克上市的母公司、在境内注册的微软（中国）有限公司、以及在中国大陆独立运营 Azure 与 Office 365 的世纪互联旗下公司。三层各自签不同的合同、开不同的发票、承担不同的责任。

## 三层结构

| 层 | 主体 | 作用 |
|---|---|---|
| 上市母公司 | Microsoft Corporation，纳斯达克 MSFT | 全球业务的最终母公司，1975 年成立，总部在华盛顿州雷德蒙德 |
| 境内法律实体 | 微软（中国）有限公司 | 在华销售、服务、签约与开票的法人主体 |
| 中国区云运营方 | 上海蓝云网络科技有限公司（世纪互联） | 独立运营并销售由世纪互联运营的 Azure、Office 365、Power BI |

中国区云服务不是"微软自己在华机房"，而是微软授权技术、世纪互联独立运营的物理分离实例：合同签署、收款、开票、运营保障、技术支持与赔偿主体都在世纪互联一方。

## 子公司与业务分部的区别

被并购进来的公司通常保留法人资格，母公司只在财报层面按分部合并，日常经营仍以子公司自己的名义进行。判断某个产品该找谁，先分清三种关系：

- **全资子公司**：独立法人、独立账号体系、独立合同，母公司的销售主体不能替它签约。
- **业务分部**：只是财报与管理口径的划分，不构成法人，对外仍由某一个法人签约。
- **品牌或产品线**：既不是法人也不是分部，只是市场名称。

> 判断：看到"某某是某集团旗下产品"时，先问它是子公司、分部还是品牌；三者的合同相对方完全不同，只有子公司能独立承担合同责任。

## 中国区云的特殊性

- **签约路径有两种**：企业客户可直接与世纪互联签在线服务高级协议（OSPA Direct），也可签间接协议并与 Azure 间接合作伙伴另签商业合同。
- **功能存在差距**：中国区 Azure 的可用服务与全球版不完全同步，新功能上线通常滞后，迁移方案要先核对目标区域是否已支持。
- **数据位置**：客户数据存放在中国大陆的数据中心（中国东部在上海、中国北部在北京），可指定区域，跨区不自动复制。
- **发票与合规**：中国区云服务的发票由运营方开具，走境内增值税链条；全球版 Azure 则是境外主体收款，两者不能混用报销。

## 产品与主体的对应

- **Windows、Office 消费者版、Microsoft 365 个人版**：通过微软账户与全球或境内渠道购买，具体收款方以结算页为准。
- **Microsoft 365 企业版、Power BI、Dynamics 365**：中国区由世纪互联运营销售；全球版由微软自身或区域经销商签约。
- **Azure 全球版与中国版**：同一品牌、两套运营体系，资源不能跨区迁移，账号与订阅也分开管理。
- **GitHub**：微软全资持有的子公司，保持独立法人地位，代码托管与 Copilot 的订阅合同落在它自身，不经过微软（中国）签约。
- **LinkedIn 等其他独立业务**：同样由各自的公司实体运营，与微软（中国）是并列关系而非上下级。
- **Copilot 与 AI 服务**：多数随 Microsoft 365 或 Azure 订阅提供，企业采购时归属看订阅合同，而不是品牌页。

## 对合作方的含义

- **合同相对方**：买中国区云资源，对方是世纪互联旗下公司；买盒装软件或全球版订阅，对方可能是微软（中国）或境外主体。
- **发票**：抬头必须与收款方一致；跨境主体通常只能提供境外票据，境内报销需提前确认财务口径。
- **数据责任**：谁是个人信息处理者，取决于实际运营方；中国区云的个人信息由运营方在境内处理。
- **违约与赔偿**：中国区云的责任主体是运营方，向微软母公司追责在法律上不成立。
- **续约与迁移**：中国区与全球版之间不是"换个区域"那么简单，涉及重新签约、数据迁移与功能重测。

## 怎么核实

1. 看结算页与订单确认邮件里写的收款主体全称，而不是页面上的品牌标识。
2. 中国区云服务查运营方的服务协议与信任中心文档，确认签约与开票主体。
3. 企业采购要求供应商提供营业执照与授权链条，确认它是直销、经销商还是运营方。
4. 用母公司年报核对业务分部与并购范围，判断某个产品是否真的属于微软体系。

## 常见误区

- **以为"微软云"都是微软收款**：中国区 Azure 的合同、发票、赔偿都在运营方。
- **把中国版与全球版当同一套服务**：账号体系、区域、功能清单、合规路径都不同。
- **拿品牌名去签合同**：法人全称与统一社会信用代码才是有效标识。
- **忽略经销商层级**：从经销商采购时，服务责任首先落在经销合同上。
- **默认数据可自由跨境**：中国区云的数据存放区域由客户指定，跨境传输另有合规要求。

## 一句话主线

微软是"全球上市母公司 + 境内销售法人 + 中国区云独立运营方"的三层结构：**日常采购看收款主体，中国区云看运营方，资本与财报看母公司**——品牌一致不代表合同主体一致。
