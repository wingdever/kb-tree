# OPPO广东移动通信有限公司

OPPO 是"终端厂商 + 端侧模型 + 系统助手"的类型，资本上不上市、不披露财报，主体是一家东莞的有限责任公司。它的 AI 入口不单独卖，随手机出货。

## 主体结构

| 项 | 内容 |
|---|---|
| 主体 | OPPO广东移动通信有限公司，曾用名广东欧珀移动通信有限公司 |
| 注册与经营 | 广东省东莞市长安镇，境内注册 |
| 资本状态 | 未上市，无公开财报与股价 |
| 股权体系 | 由创始人与管理团队通过境内控股体系持有，关联公司众多 |
| 业务 | 智能终端制造、移动互联网服务、海外销售 |

## 产品与主体

- **小布助手**：系统级语音与智能体入口，随 ColorOS 预装。
- **安第斯大模型**：端云协同的模型体系，端侧做轻量推理，云端做复杂任务。
- **互联网服务**：应用商店、云服务、账号体系由境内服务主体承担。
- **海外机型**：不同国家版本由当地主体或授权渠道承担合规责任。

## 对合作方的含义

- 未上市，供应商准入要看工商、诉讼、渠道与出货数据。
- 预装与系统级合作涉及权限与数据，条款比普通应用严格。
- 端侧推理意味着部分数据不出设备，处理者角色与纯云端不同。
- 海外版本适用当地法规，境内合同不能覆盖境外销售。

## 怎么核实

1. 工商核对主体、股东与关联公司，确认控股体系。
2. 预装合作核查系统权限清单与数据留存策略。
3. 海外项目确认当地主体与认证。
4. 售后与保修条款看清承接主体是厂商还是渠道。

## 常见误区

- **以为小布是独立 App 公司**：它是系统能力的一部分。
- **把未上市当成没有资本实体**：有限责任公司同样有股权与控制关系。
- **忽略端云分工**：数据在哪一侧处理，责任就在哪一侧。
- **用出货量推断财务健康**：出货与利润、现金流不是一回事。

## 一句话主线

OPPO 是未上市的终端公司：**资本看股权体系，产品看系统助手，合规看端云分工与销售地**。
