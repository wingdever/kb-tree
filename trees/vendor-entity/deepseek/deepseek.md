# 深度求索（DeepSeek）

DeepSeek 的结构比它的模型简单：一家杭州的有限责任公司，由量化基金孵化，创始人持有较大比例，从未上市。它的特殊性在于"开放权重 + 低价 API + 消费级应用"三条线同时跑，而资本层面几乎不融资。

## 主体结构

| 项 | 内容 |
|---|---|
| 主体 | 杭州深度求索人工智能基础技术研究有限公司 |
| 成立 | 2023 年 7 月，注册在杭州拱墅区 |
| 孵化背景 | 由幻方量化宣布成立，团队与算力资源来自量化体系 |
| 股权 | 创始人为自然人股东并持有较大比例，另有员工持股平台 |
| 资本状态 | 未上市；2026 年完成一轮融资，规模属报道口径 |

## 产品与主体

- **开放权重模型**：模型权重对外发布，商用需遵守模型许可。
- **API 服务**：按 token 计费，价格策略是它的核心竞争力之一。
- **消费级应用**：DeepSeek App 与网页端，面向普通用户的对话入口。
- **技术报告**：训练细节对外披露程度较高，是评估能力的补充材料。

## 对合作方的含义

- 未上市且融资轮次少，公开财务信息稀缺，供应商准入依赖工商与履约记录。
- 开放权重不等于免费商用，许可证对再分发与衍生模型有限制。
- API 价格低但服务等级协议相对简单，关键业务要自建降级方案。
- 消费级应用与 API 的数据条款不同，别混用。

## 怎么核实

1. 工商核对主体名称、注册资本与股东结构。
2. 模型许可看官方仓库的许可证文本，不看二手解读。
3. 融资与估值以公司或投资方披露为准。
4. 关键业务评估时自测延迟、限流与故障恢复，不只看价格表。

## 常见误区

- **以为 DeepSeek 是幻方本身**：它是独立法人，幻方是孵化方与关联方。
- **把开源权重当成无限制商用**：许可证有再分发与署名要求。
- **以为低价等于低可用性**：价格与 SLA 是两套指标，要分别评估。
- **用传闻估值写尽调**：融资金额与估值口径差异极大。

## 一句话主线

DeepSeek 是"轻资本、重技术"的模型公司：**主体是一家杭州有限公司，产品是权重、API 与应用三条线，合规看许可证而不是看宣传**。
