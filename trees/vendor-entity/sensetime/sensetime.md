# 商汤集团股份有限公司

商汤是"学术团队创业 + 开曼上市 + 协议控制境内实体"的组合，且明确没有最终控股股东。它的智能体产品偏生产力场景，不完全是消费级助手，这是判断它是否算 C 端 Agent 供应商的关键。

## 主体结构

| 项 | 内容 |
|---|---|
| 注册地 | 2014 年 10 月在开曼群岛注册成立的豁免有限公司，不同投票权控制 |
| 上市 | 2021 年 12 月 30 日在港交所主板上市，代码 0020（港币柜台）、80020（人民币柜台） |
| 控股状态 | 年报明确无最终控股公司及控股股东，股权分散 |
| 境内衔接 | 通过一系列合约安排将上海多家运营实体的业绩合并入账 |
| 业务线 | 生成式 AI、传统视觉 AI、智能汽车三条 |

## 产品与主体

- **日日新大模型**：对外以模型服务与行业方案交付，合同落在境内运营实体。
- **办公智能体**：小浣熊系列面向文档、数据分析等生产力场景，属于 C 端可用但不以消费级流量为目标的产品。
- **智能汽车与视觉 AI**：项目制交付，签约主体与交付主体可能不同。
- **AIDC 算力**：对外提供算力服务，属于基础设施类合同。

## 对合作方的含义

- 项目制合同要写清交付主体与验收标准，协议控制结构下母公司不当然是合同方。
- 数据责任按场景分：办公文档、车载数据、公共场景视觉数据的合规要求差别很大。
- 无控股股东意味着重大决策靠董事会，长期合作要关注治理稳定性。

## 怎么核实

1. 用年报核对合并联属实体清单，确认目标业务在哪家上海公司。
2. 合同抬头与年报披露的实体名称比对，避免用到未纳入合并的关联方。
3. 车载与视觉类项目额外核查资质与数据合规方案。
4. 大额合作查看董事会与治理披露，判断决策链长度。

## 常见误区

- **以为商汤只有一个境内公司**：多家上海实体通过合约安排合并。
- **把"无控股股东"理解成没有实控人**：治理靠董事会与投票权架构。
- **把视觉 AI 的老合同模板套到生成式 AI**：数据与责任条款完全不同。
- **以为港股代码 0020 与 80020 是两个主体**：柜台不同，主体相同。

## 一句话主线

商汤的资本在开曼、运营实体在上海、业务分三条线：**签合同找合并范围内的境内实体，评估稳定性看治理结构，判断产品属性看它是不是真的面向普通消费者**。
