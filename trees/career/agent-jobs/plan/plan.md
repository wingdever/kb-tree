# 求职计划与漏斗

求职是一个有明确起止的短周期项目，不是“有空就投”。没有目标和漏斗，投递会变成情绪消耗；有节奏和复盘，才能知道问题出在定位、证据还是表达。

## 周期与目标

- **4 周冲刺**：已有作品集与简历，目标 10–20 个高匹配岗位，争取 3–5 个初面。
- **8 周建设**：作品集或能力有缺口，先用 3–4 周补项目与评测，再进入投递。
- **在职求职**：每周固定 5–8 小时，优先内推与高匹配岗位，避免海投。

目标要写成可检验的句子：例如“拿到 3 个 Agent 应用岗初面”，而不是“找到好工作”。

## 漏斗与指标

记录五层：投递 → 回复 → 初面 → 技术/终面 → Offer。

- 投递多、回复少：先改定位与简历，不是继续投。
- 回复多、初面少：检查沟通与岗位匹配。
- 初面多、技术面少：补基础与项目表达。
- 技术面多、Offer 少：补系统设计、评测与行为面。
- Offer 少但都走到终面：可能是薪资、签证或竞争问题，不一定是能力问题。

## 每周节奏

- 周一：选 3–5 个岗位，做 JD 映射，定制简历。
- 周二到周四：投递、内推、跟进；每天留一段固定时间补弱项。
- 周五：复盘本周漏斗，更新项目文档与面试故事。
- 周末：做一次模拟面试或项目迭代，不安排过量社交。

## 复盘

每轮面试后 24 小时内记录：被问什么、答得怎样、哪道题卡住、下次怎么改。把重复出现的问题归入三类：知识缺口、表达缺口、证据缺口。知识缺口补内容，表达缺口练结构，证据缺口回项目里补。

## 谈判与收尾

- 拿到 Offer 后先确认书面条款：薪资结构、试用期、股权、竞业、地点与远程安排。
- 有竞争 Offer 时再谈，不要虚报；谈的是总回报与职责，不只是月薪。
- 拒绝要及时、简洁；保留关系，行业圈子很小。
- 入职前确认汇报对象、团队现状与第一个交付，避免“入职即救火”。

## 一句话主线

用周节奏推进，用漏斗定位问题；求职不是比谁投得多，而是比谁迭代得快。
