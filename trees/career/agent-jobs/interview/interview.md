# Agent 岗位面试

Agent 面试考的不是“知不知道某个框架”，而是能不能把模糊目标拆成可运行、可评测、可回退的系统，并在追问下说清自己的取舍。

## 面试流程

常见顺序是：简历筛选 → 招聘者沟通 → 代码或作业 → 技术面（基础 + 系统设计）→ 项目深挖 → 终面/行为面 → Offer。不同公司会合并或增减；海外岗位可能加一轮跨时区沟通或背景调查。

## 代码与基础

- 代码：数组/字符串/哈希、并发与异步、API 调用与错误处理；不一定是算法难题，但要求写干净、能跑。
- 模型基础：上下文窗口、温度、结构化输出、工具调用、流式、token 计费、幻觉与局限。
- 检索基础：切块、嵌入、向量索引、BM25、混合检索、重排、召回率与精确率。
- Agent 基础：循环、状态、工具、记忆、规划、反思、失败回退、多 Agent 的成本。

## Agent 系统设计

用固定框架回答，避免东一句西一句：

1. **目标与边界**：用户是谁、任务是什么、哪些事不该做。
2. **状态与循环**：单轮还是多轮、状态存哪、何时停止、最大步数。
3. **工具**：工具清单、schema、权限、超时、重试、幂等与失败回退。
4. **知识与记忆**：要不要 RAG、检索什么、记忆存什么、何时清理。
5. **评测**：黄金集、通过率、平均步数、P95 延迟、单任务成本、人工接管率。
6. **护栏**：注入、越权、数据泄露、成本失控、可观测与告警。

设计题没有标准答案，但要能说清“为什么这样选”和“失败时怎么办”。

## 项目深挖

面试官会沿着你的作品集追问：你负责哪一部分、为什么这样设计、指标怎么来的、最难的失败是什么、如果重做会改什么。准备两个故事：一个技术失败，一个取舍或协作失败；每个都要有具体证据。

## 行为与反问

- 行为面看：冲突怎么处理、优先级怎么定、失败怎么复盘、如何面对模糊需求。
- 反问看：团队产品阶段、数据与算力、评测文化、值班与交付节奏、成长路径。反问不是走形式，它也在帮你选岗。

## 一句话主线

面试是把“能力栈”翻译成“可运行系统 + 可验证结果”；背概念不如讲清取舍。
