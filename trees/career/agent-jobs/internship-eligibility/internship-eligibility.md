# 实习资格与替代入口

“实习”首先是一个身份通道，不是能力等级。多数正式实习项目面向在校生，因为它们要与学校、学籍和毕业时间对齐；已经毕业或空窗几年，不等于不能进这行，而是要走不同的入口。

## 正式实习的常见门槛

- **在校身份**：多数公司要求学籍或在读证明，部分项目只要特定毕业年份的学生。
- **时间条件**：能连续实习 3–6 个月，每周到岗若干天，实习结束后回学校继续学业。
- **项目类型**：校招实习、暑期实习、日常实习的资格与转正规则不同；有的只面向当年应届生。
- **协议形式**：通常签实习协议，不建立正式劳动关系；报酬叫实习补贴，保障与劳动合同不同。

所以“必须是在读学生吗”的准确回答是：**法律没有统一规定，但绝大多数正式实习项目按在校生设计**。

## 已毕业/空窗期能不能实习

- 正式校招实习项目通常会按毕业时间、学籍状态筛选，已毕业多年的人大概率过不了简历关。
- 小公司、创业公司、项目制团队有时愿意接受非在校生以“实习”名义工作，但这通常按劳务或兼职处理，不是学生实习。
- 个别公司会设“职业转换实习/实训岗”，数量少、信息不透明，要单独核实合同与转正规则。
- 如果实际接受公司管理、长期全职提供劳动，是否构成劳动关系要看事实，不只看协议名称；这会影响工资、社保、工伤与解约保障。

空窗期本身不是法律障碍，也不是能力否定；真正的障碍是**入口不匹配**。

## 非学生身份的替代入口

- **社招初级/助理岗**：最直接。用作品集证明能搭链路，接受从模块做起。
- **项目制/外包/驻场**：进入快、能接触真实交付，但技术沉淀取决于项目质量。
- **兼职/远程协作**：适合先积累案例，但要注意合同、付款与知识产权。
- **开源与社区项目**：用可公开的代码、文档和评测建立证据，绕过学历与身份筛选。
- **实训/学徒项目**：短期集中补工程能力，但要判断是否只是卖课。
- **自己做一个可运行产品**：对 Agent 开发尤其有效；有用户、有失败处理、有评测，比“实习生”标签更有说服力。

## 合同与保障

看到“实习”两个字，先问清四件事：

1. 签实习协议、劳务合同还是劳动合同；
2. 有没有工资/补贴、保险、工伤保障；
3. 工作时间、管理关系与考核方式；
4. 知识产权、保密、竞业与转正条款。

长期全职却只给“实习补贴”，是风险信号；已毕业人员尤其要避免用实习名义替代正式用工。

## 应届生身份

在中国，择业期内的应届生身份可能与社保、劳动合同、档案与派遣状态有关。如果你还在择业期内，签劳动合同或交社保前先核对当地规则；如果已经毕业多年，这一条通常不再重要。不要为了保留“实习生”身份去读一个不需要的学位，成本远高于收益。

## 判断顺序

1. 还在读且能提供在读证明：优先走正式实习。
2. 刚毕业、仍在择业期：同时看校招入口与社招初级。
3. 已毕业多年：直接走社招初级、项目制、兼职或开源证据，不硬挤实习通道。
4. 公司愿意收非在校生“实习”：先看合同与保障，再决定是否接受。

## 一句话主线

“实习”是身份通道，不是能力等级；不在读就换入口，不要硬挤。
